# 炼药作坊生成动作样板 r4

本目录保存用户决定放弃 Aseprite 绘制后重新生成的候选美术。**当前为旅行博主的浏览器动作审稿，没有替换 Godot 正式关卡，没有通过用户验收。** 其他五位博主尚未按这套方法完成。人物、器物、场景和火焰均来自直接图像生成；原始图片保留，不用本目录覆盖原立绘。

交互预览源码为 `tools/generated_art_review.html`，本地审稿页为 `artifacts/pixel-v2/review-r4/index.html`。页面的温度式火势变化只用于检查动作联动，不是炼丹正式温控或评分。人物与背景在 500×300 审稿画布合成；生成原图并非已经逐像素整理完毕的 500×300 原生生产资产。

## 身份与文化边界

角色直接参考 `arts/素材合集/sprite及立绘/Sprite/角色/旅行博主.png` 的脸、眼睛、灰玫瑰发色、双低辫与黄色帽子。装束变为工作服；是否充分保留身份仍由实际对照和用户试看决定。

环境参考 `InheritanceTasks/Art/Pixel/v2/review/generated-workshop/workshop-source-r2.png`，设定是专用炼药作坊。风箱、炉体和炼药器物是游戏场景设计，**尚未考证为夏氏丹药真实设备复原**。本目录未引入网上照片作为可发布资产。参考图与原文件均保留。

## 透明与固定器物处理

所有生成 PNG 当前都是不透明 RGB。前两版动作条生成了假棋盘格，后续改用纯绿色技术底。浏览器在内存中处理绿色底与局部绿色溢色，原 PNG 不变；不能据此把源文件称为原生透明资源，也不能把一次色键处理等同于边缘整理完成。

原整条动作的第 5、6 帧改变了木箱形状和铁箍位置。当前预览使用第一帧同一箱体，人物加活动拉杆另层播放，固定风嘴对准炉口。活动杆用同一纹理片延长，并在固定入杆位置遮挡；这是审稿合成办法，还需逐帧确认手、拉杆和入杆点是否自然。箱体自身不应随鼓风变窄、换纹理或移动。

火焰使用独立相位和延迟响应，不能将整条火图简单等分三行；三档实际底边不同，裁切矩形见 manifest。火焰限制在炉口内，避免盖住药锅和砖唇。黑底 screen 合成不能替代正式透明资源的视觉检查。

## 未完成与已知问题

- 人物脚位、衣形和部分肢体在生成帧之间仍有变化，第 6→7 帧回位跨度需要正常速度检查；没有宣布动作平滑或身份验收通过。
- 图集原尺寸不能被 4×2 整除。预览采用固定分格计算，无逐人物包围盒缩放；源像素边界与成片像素密度仍需整理。
- 绿色边缘、手杆接触、人物与环境比例，需要在白底、黑底、实际场景及播放状态下继续复核。
- 当前没有接入 Godot 的语义动作、温控状态、实际音效、六角色换装或完整教学 UI。
- `artifacts/pixel-v2/review-r4/generated-sheet-audit.json` 和同名 Markdown 记录原图静态审计；它们不代表正常速度播放、引擎验证或用户认可。
- `manifest.json` 的合成参数记录生成时预览源码快照；之后修改 HTML 应同步元数据，不能把旧快照当作运行权威。

换用图像生成解决制作方法选择，不自动解决帧间一致性。P1 仍保留用户试看关口，未通过前不批量铺开错误模板。
