# 《楚物志 · 数字版》客户端

本游戏为华中科技大学新闻学院和法学院联合申报的省级大创&挑战杯创业项目《楚物志：荆楚非遗数字活化与文旅桌游生态构建》系列桌游的线上数字孪生版。

## 版本号：Beta 0.1.0 Demo

**已实现玩法和功能：**

* **桌游基本GamePlayer逻辑**，包括但不限于：全局资源计算分配与管理器（ResouceManager）、全局回合状态机管理器（TurnManager）和全局游戏管理器（GameManager）等，实现基本的回合轮转、卡牌与资源分配功能；数据结构与卡牌资源：将游戏中各类卡牌资源化，自动遍历加载，可永久持续扩展；
* **独特规则与游戏逻辑：** 严格根据桌游说明书复现线上孪生版本，有自动计分系统，规则虽然基础但完整、可玩性高；全部非遗牌、全部市级食物牌已导入游戏，内容丰富；
* **游戏地图：** 实现桌游中功能繁多的地图与具体地块功能，包括非遗收集点、食物商店、风景、打工点，以及各类特殊地形；地图高度适配HUD，且通过Camera2D实现镜头动态跟随缩放与俯瞰整张地图的两种视角模式；
* **交互界面设计：** 有完整且优美的GUI设计，实现基本交互需求；
* **弹窗插入：** 实现非遗牌查看、食物背包、食物商店等弹出式窗口生成及其内部元素动态生成的逻辑；
* **游戏前设置：** 实现开始游戏前动态设置玩家数量、并随着数量改变动态生成不重复的角色信息设置选项，每个角色栏位可独立设置名称、出生点和职业，自动查重和检查合法性，并根据设置的角色信息切换至游戏主场景、开始游戏；

**待实现玩法和功能：**

* **玩家职业分化：** 不同职业身份目前只有形象区分，待后续加入职业技能区分；
* **省级和国家级食物牌：** 市级食物牌的功能是相同的，所以目前游戏中只有全部的市级食物牌，待后续加入和实现各类省级和国家级食物牌的独特功能；
* **“神话传说”类非遗牌：** 神话传说类非遗牌由于具有实时可用判定和插入结算特性，实现逻辑较为复杂，游戏中目前还无法使用，待后续实现；
* **事件牌：** 游戏中目前还没有实现事件牌和事件系统；
* **交易系统：** 游戏中目前还没有实现玩家间的交易功能以及地图上的非遗研究所；
* **成就牌：** 游戏中计分系统目前只统计基础分数和组合分数，没有统计成就分数，也没有加入成就系统；
* **国家级非遗任务：** 目前在游戏中抽取到国家级非遗牌会直接获取，不需要做任务，待后续加入任务系统；
* **HUD完善：** HUD还有许多需要完善的功能，如重新开始、设置、游戏内规则便捷查询、地块具体信息实时显示等；
* **音效与BGM：** 目前游戏还没有任何音效；

本项目全部开源，欢迎游玩体验和参与开发改进。
