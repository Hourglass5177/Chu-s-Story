# 《楚物志 · 数字版》客户端

本项目是荆楚非遗主题桌游《楚物志》的 Godot 数字孪生版本，由华中科技大学新闻学院和法学院联合项目组开发。

当前版本：**beta 0.4.0**（Godot 4.6.2）

## 当前功能

- 新版开局流程：首页选择模式，设置真人与电脑人数，再逐位设置名字、职业和出生点，经阵容总览确认后进入对局。
- 1–6 人本地回合制对局，包含 2D6 移动、精力路径、回合末淘汰、15/20/25/30 分目标与累计淘汰 2 人的终局判断。
- 完整地图交互：全局/追踪视角、拖拽缩放、地块信息、风景、打工、商店、非遗点、事件格和四个共享研究所入口。
- 非遗牌收集、使用、转移、研究所买卖、动态组合计分和牌区提示。
- 60 张统一食物牌库（20 市级、36 省级、4 国家级）及其个性化效果、持续状态、多人响应和回库流程。
- 40 张事件牌、保留事件牌、地图选格/选人、响应链、超时裁定和研究所事件。
- 六种职业技能、六项本局成就，以及分项揭晓、排名重排和冠军展示的正式结算界面。
- 统一的卡牌获得、失去和转移动画，以及棕金色弹窗、简洁提示和右侧手牌 HUD。
- 共用的数字版游戏指南：六步快速上手、分层规则图鉴、中文搜索、情境跳转与响应式导航。
- 本机共享探索图鉴：非遗、职业和风景公开，食物、事件和成就在游戏中首次公开后永久翻开。

本地游戏至少需要 1 名真人玩家，总人数不超过 6 人。电脑席位本阶段仍由同一台设备顺序操作，尚未接入 AI；网络游戏与教学模式仅保留按钮和扩展接口，暂未开放。

国家级非遗线下任务、音效/BGM、网络游戏、教学关卡和机器人 AI 仍未实现；旧 Demo 说明不作为当前规则依据。数字版相对纸质说明书的变化见 `docs/游戏说明书（数字版变更记录）.md`。

## Beta 验证

完整验证入口：

```powershell
./tools/verify_beta.ps1 -GodotPath "路径\Godot_v4.6.2-stable_win64_console.exe"
```

该命令先校验指南 Markdown 与运行时目录完全同步，再执行干净导入、主场景启动、全部 GUT 测试及 2/3/6 人三种策略的 9 局模拟冒烟，并校验测试数量不为零。运行前应关闭正在占用本项目的 Godot 编辑器。

标准 972 局平衡批次：

```powershell
./tools/run_balance_simulation.ps1 -GodotPath "路径\Godot_v4.6.2-stable_win64_console.exe"
```

结果写入被 Git 忽略的 `artifacts/`；每个失败种子均保留终止原因、最后状态和交互快照。详见 `docs/Beta稳定性与平衡测试.md`。

本项目开源，欢迎试玩与参与改进。
