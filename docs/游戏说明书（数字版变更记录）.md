# 《楚物志》数字版规则变更记录

本文档只记录数字版相对旧版《游戏说明书》的规则变化。旧版说明书原文件保持不动；开发、测试和游戏内说明以本文档及当前已确认的实际原型规则为准。

## 已确认变更

### 非遗收集

- 在非遗点收集非遗牌消耗 1 点精力，不再消耗 2 点精力。
- 成功收集非遗牌后仍停留在 ACTION，不自动结束回合。
- 已使用或被事件弃置的非国家级非遗牌进入全局研究所；国家级非遗牌不进入研究所。
- 国家级非遗牌暂按普通非遗牌获取并正常计分，但不能使用；原线下互动任务暂不实现。
- 非遗牌的地区、分类和总数量以工程内实际 `.tres` 资源动态统计为准，不沿用旧说明书中的固定数量。

### 回合、移动与胜利

- 正式多人局累计淘汰 2 名玩家才按分数结算；2 人局同样需要累计淘汰 2 人。任意玩家达到 20 分时可提前结算。
- 精力降到 0 不会立即淘汰；仅在该玩家完整回合结束、即将交接下一位玩家时判断。移动后精力为 0 仍可进入 ACTION，并可通过食物等效果恢复；回合末精力高于 0 则存活。
- 地图寻路同时受骰子步数与当前可支付精力约束；同一终点优先选择耗能最低、其次步数最少的合法路线。
- 普通移动动画完成前暂停移动计时并锁定阶段与操作按钮。超时原地停留、事件传送和换位不记录为普通到达，也不触发落点。
- 手工技艺类非遗牌每个 MOVING 阶段最多发动一次，不能连续叠加翻倍。

### 全局研究所

- 襄阳、宜昌、荆门、武汉的四个研究所入口共享同一库存；新游戏库存为空。
- 每次普通移动真实到达研究所后可进入一次；停留原地、传送或换位到达均不能进入，离开后再次普通移动到达可重新进入。
- 每次访问最多购买 3 张，可出售任意数量；达到购买上限后仍可出售。
- 非国家级非遗牌售价为 `250 + 50 × 基础分`，买价为售价的 2 倍。刚出售的牌可以按正常买价重新购回，并计入本次购买上限。
- 国家级非遗牌不可出售、购买或进入研究所；被“弃任意手牌”效果弃置时直接离场。
- 主动使用或被事件弃掉的非国家级非遗牌自动进入研究所，不获得出售收入。
- 打开研究所时暂停阶段计时和普通操作；关闭后仍处于 ACTION，并恢复完整 15 秒。

### 食物牌

- 市级食物牌使用后固定恢复 2 点精力。
- 每名玩家每回合最多享用 1 张食物牌，新回合重置次数。
- 删除“恢复 1 点精力并获得 100 积分点”的第二种使用选项。
- 省级、国家级食物的特殊效果尚未实装；食物分级价格在特殊效果完成后再统一调整。

### 计分与地图交互

- 地域的“同城 5 张”、“集齐全市”与“江汉三市”加分在数字版 UI 中统称为“地域组合分”；计分数值不变。
- 默认全局视角可左键拖拽地图并使用滚轮缩放，缩放范围为全图大小至 3 倍。`ALT` 切换玩家跟踪视角；跟踪视角仍可缩放，但不可拖拽。

### 事件牌

- 玩家到达事件格后，在进入行动阶段时自动抽取并结算事件牌。
- 事件结算完成后恢复完整的行动阶段计时，默认不会结束或跳过行动阶段；只有牌面明确规定时才改变阶段。
- 事件展示、选择和响应期间暂停行动计时；每一步限时 15 秒。可选操作超时放弃，强制选择超时从合法项中随机选择。
- 事件牌使用后进入弃牌区，本局不洗回；牌库耗尽后事件格无事发生。
- 可保留事件牌公开抽取后收入持有者的私密手牌区，在合法时机使用或响应。
- 金蝉脱壳和移花接木只响应其他玩家卡牌作用到自己的部分；群体效果的其他部分继续结算。转移后的新目标可以继续响应。
- 神话传说类非遗牌只响应其他玩家的食物牌或事件牌；使用范围不扩展到非遗牌。
- 事件造成的传送和换位默认不触发目标格效果；资源或目标不足时执行最大合法数量。
- `鉴往知来`、`釜底抽薪`、`展艺共研`、`市集淘珍`已接入全局研究所并进入牌库；仅 `孤注一掷`因依赖职业技能暂不入库。
