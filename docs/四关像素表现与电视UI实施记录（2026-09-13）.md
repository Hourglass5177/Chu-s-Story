# 四关像素表现与电视 UI 实施记录（2026-09-13）

本记录覆盖六角色运行快照、电视宿主，以及天门糖塑、鼓盆歌、鄂州雕花剪纸、黄梅戏的独立像素表现。它不代替十五关最终验收，也不把画面采样当成真人体验。

## 已接入

- 正式挑战从实际职业取得 `avatar_id` 快照；图鉴练习可选择六位博主，最近选择保存于本机。外观不写入共享职业或非遗卡资源。
- `HeritageTaskPresentation`、`HeritageAvatarAppearance` 提供可选舞台、六角色动作、封面、故事分镜、器物与锚点入口。缺失时保留旧画面回退。
- 电视宿主包含准备、实际开始、暂停、设置、退出确认、结果与技术错误承载；已完成教学可跳过或重学。准备时任务保持 IDLE，未播放媒体、未发进入发现信号。
- 音量只调小游戏专用音频总线；视觉辅助与减少动态效果即时同步至活动任务。节拍校准在教学期间开放，不释放外部暂停原因；失焦冻结节拍，恢复后平移原点，不补播暂停期间的音。
- 结果页显示实际像素终态。结算与退款仍立即、单次触发，主动退出仍先结算再直接返回。黄梅戏逐句结果保留滚动区域和固定可见的返回入口。
- 补齐保留玩法的鼓盆歌、剪纸、神舟首次可操作教学：三拍复现、第一段刻线并松开停刀、左右回正并收住惯性。使用同一场景和正常输入；练习及倒数不扣正式时间，完成后重置 RNG、进度、误差与正式局状态。教学版本 2 独立保存，后续默认跳过并可重学。黄梅戏每次必要的听示范仍保留，不另加麦克风练习。

## 素材与接入文件

四关原图、提示词和参考说明位于 `InheritanceTasks/Art/Pixel/v1/source/craft-art-generation-log.json`，源图保留初版与修订版。`craft-asset-manifest.json` 记录原图和运行 PNG 的 SHA-256、尺寸、透明像素数量；`craft-presentation-entries.json` 是可并入主资源清单的四项入口。

每关已制作六角色、六关键姿势图集（ready / prepare / action / release / miss / recover），角色行顺序为 travel / life / business / food / adventure / magic。运行时统一为 128×128 单帧；师傅、糖泡与双手使用独立图集。背景 500×300，黄梅戏闭幕与开幕各一张。

`tools/build_craft_pixel_assets.py` 调用项目 sprite 管线进行绿底分离、透明噪点清理、统一尺寸和锚点测量，不覆盖原图。糖塑吹管端点逐角色逐帧测量；剪纸刀尖锚点为操作帧 (11,4)、停刀帧 (12,4)，相对于 160×160 图格。重新生成后必须连同 `runtime/craft/anchors.json` 一起交付。

四个独立绘制场景在 `InheritanceTasks/Presentation/Stages/`。任务脚本只向表现层提供状态；糖塑增长、余胀、目标范围、三轮两胜，鼓盆歌节奏和平均误差，剪纸路径/偏离容差，黄梅戏录音与评分均保留已有规则。

- GPU 当前工程采样：`artifacts/craft-pixel-ui/` 含四关实际场景、六角色以及闭幕/开幕画面。`tools/inspect_heritage_craft.gd` 为视觉采样；其黄梅戏开幕使用阶段预览和拒绝录音的适配器，没有打开麦克风。
- `tools/inspect_heritage_results.gd` 在真实渲染循环中用普通鼠标事件完成剪纸，记录 `progress=0.99516531775056` 和“挑战完成”，并截取成果。黄梅戏结果图使用明确标注的合成 UI 数据，只验证分项滚动和按钮布局，不是演唱通过证据。
- 电视尺寸覆盖 1280×720、1920×1080、2560×1600，及挑战中调整。1280×720 实际测得开始按钮高 44.10 像素、辅助正文 18.45 像素；黄梅戏歌词另设至少 20 实际像素。

- `tools/play_gupen_pixel_host.gd` 进一步在当前 D3D12 像素 Host 中，经普通点击开始并发送确认键事件走完鼓盆歌三轮：正常操作约 18.27 秒、三轮通过；首轮每拍故意迟 450 毫秒后约 18.72 秒结束，后两轮恢复并以两轮通过。每例只结算一次，未改内部得分、阶段、时间或成功结果。报告和四张实际画面在 `artifacts/gupen-pixel-play/`；这是图鉴练习入口的正式计时玩法，不另行验证正式对局扣费。

## 视觉检查与待办

已检查糖塑吹管与糖泡连接、膨胀尺寸、六角色辨识；剪纸刀尖与实际输入位置、花样不越出纸面；鼓盆歌示范者/参与者与轮次对比；黄梅戏真实视频、歌词与开幕人物的分层。源图一度存在接近透明的零散像素，导致糖泡错误缩小，现已在边界测量前清理。

生成的六关键帧属于第一套可用动作资源，尚不能称为精修动画或完整美术验收。鼓盆歌的鼓板形制、握法，以及剪纸实际刀/蜡盘使用仍需用户补充视频核对。当前鼓盆歌采用现有合成交互短音，不能当作真实鼓盆歌原声或鼓板采样；声音素材需求仍保留。

鼓盆歌传习场景是游戏化教学表现，其项目实际具有丧俗背景；公开依据见湖北省非遗资料：<https://wlt.hubei.gov.cn/hbsfwzwhycw/bhcc/fydt/jzs/202005/t20200525_2295659.shtml>。双鸟花枝为原创花样，最后刻线组成成品上缘。糖塑非线性与余胀不作为真实工艺参数。黄梅戏博主戏服为《女驸马》主题角色扮演，动画不冒充实时音准判断。
