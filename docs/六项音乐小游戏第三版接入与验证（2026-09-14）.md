# 六项音乐小游戏第三版接入与验证

当日后续增量已升级谱面3与教学5，教学改为17步正式混音节选、伙伴独立演出轨；三项后景演员有新候选。下文是此前的v2混音接入快照，最新实施、真实教学回放和未完成项以[教学与演出分离记录](六音游教学与演出分离实施（2026-09-14）.md)为准。原混音切句仍待听审。

本记录对应 2026-09-14 当前工作区。六关已接入新生成背景、36 份博主动作图集、独立伙伴/演员和 v2 游戏音频编排。原始生成图、原博主、授权视频保留。用户尚未验收本轮音乐美术或手感；音频短句尚未经过可听审人员审核。

|---|---|---|

| 土家族撒叶儿嗬 | 左右落脚、同侧重复和停步；同向领舞与足边图形 | 40 秒 |
| 荆州花鼓戏 | 短应答、长按、收声；主唱和参与区区分 | 39 秒 |
| 汉剧 | A/D 直接选左右追光位置；演员跨台与原位保持 | 40 秒 |
| 提琴戏 | 左右短弓、长弓与收弓；源姿态随保持进度变化 | 39 秒 |
| 鼓盆歌 | 三个固定短节奏句；师傅示范、入拍交接、玩家复现；两轮通过 | 33 秒 |

六关继续共享音频时钟和判定，小关保留独立教学、输入语义和舞台。起点窗口 ±180 毫秒、收尾 ±220 毫秒；长按为 30% 起点、30% 保持、40% 收尾；一般通过线 70%，休止贡献上限 20%。空击有累计惩罚，自动重复和重复按当前追光位置不额外得分。休止检查包含提前持有、错误位置和先错后对，按带时间戳的边沿重建，避免帧率改变休止评分。

教学版本 4 按概念示范和练习；双拨必须两次按下，长按必须实际保持与松开，停顿必须停手。失误重试当前概念，跳过不记录完成。预备提示可同时显示，长按提示保留至收尾判定窗口。暂停冻结音乐和姿态，恢复倒数后提供长按续接窗口。校准使用预混提示音的音频时间，保存设备偏移，丢弃不稳定采样。

六种即时操作反馈分别对应拨弦、落脚、开口、灯位、运弓和鼓击。它们是自制游戏反馈声，不是已经确认的传统乐器采样。

## 音频、来源与听审

`InheritanceTasks/Audio/rhythm-v2/manifest.json` 保存原件路径、原件哈希、切入切出点、混音位置及最终哈希。`tools/build_rhythm_v2.py` 是可编辑的编排入口；每关保留完整游戏混音、教学和前 10.5 秒样板。原声没有变调或时间拉伸。

丝弦、花鼓和提琴将选段放入明确的示范/回应空间；舞蹈和汉剧保留连续片段并标记操作事件。鼓盆歌缺少授权传习原声，当前三个固定节奏为合成游戏练习，不称为鼓盆歌传统曲牌。

所有谱面均标为 `game_arrangement_pending_listening`。本轮没有可用于主观听审的音频感知过程。以下必须具体听审，不能由波峰或加载成功代替：

- 丝弦四段选材的 3.4 秒片段是否截断实际乐句；两次拨弦间隔和交接提示是否自然。
- 花鼓戏示范句与玩家应答空间是否易辨；长音收束提示与演出感觉是否协调。不把未确认声部叫作真实帮腔。
- 提琴戏片段自然边界、运弓反馈音是否过于机械；游戏弓向不作为录音实际弓法转录。
- 撒叶儿嗬原片的鼓点、重心变化与明确图形之间是否容易跟随；当前编排不称真实舞步谱。
- 汉剧《丛台别》演员移动与操作事件是否符合句势；该混音与其他关的主观响度仍需对齐。
- 鼓盆歌师傅示范与复现首击的可预测性；等待用户补充带原声、双手和鼓板完整可见的视频后再校对器物及节型。

## 生成资产与接入

源、提示词和候选迭代位于 `InheritanceTasks/Art/Pixel/v3/source/<task>/`；运行图位于 `runtime/<task>/`，六份干净表现资源位于 `resources/`。导出入口为 `tools/export_music_v3.py`。

人物保留 503×781 或 384×512 的原始单帧尺寸与原色，六关均使用 1000×600 表现视口。背景保留生成图细节。原图实际为技术绿底时只进行去底和切片，不标成原生透明；花鼓旅行博主的源图本身有透明通道。没有重新量化到固定 16/32 色，也没有把人物先压小再放大。新 `.tres` 从零组织引用，没有未使用的 v1 图集声明。

各关使用自己的预备、操作与收尾姿态。汉剧人物整身不翻转；提琴长弓用五个源关键姿态按保持进度选帧，另一弓向反向选序，不切回旧的低分辨率肢体层。领舞、鼓手、伙伴、主唱和教师分别显示。

本轮实际画面检查修正了花鼓演员站在台阶上的摆位、鼓盆交接条遮脚、丝弦伙伴切片边界黑线。最后又把提琴提示移至手弓下方，并清除六份提琴图集中与主体断开的少量邻格碎片；源文件未改。**提琴最后两项小修发生在本专项渲染之后，须由随后完整导入和正式 Host 画面复核。**

文化细节按来源与游戏创作分别记录：花鼓、汉剧 NPC 对照已有同场演出抽帧；提琴的短琴杆、两侧双轴和抵腰姿态参考湖北非遗资料，具体弓法仍为游戏化推演；鼓盆歌鼓具仍为待录像核对的传习候选。三弦细部、戏服附件和连续全身舞步不能因新图片生成完毕就标为考证完成。
