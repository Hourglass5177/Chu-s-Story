# 《楚物志》数字版游戏指南 UX 设计

## 目标

指南不再是一篇盖住游戏的长文章，而是一套可浏览、可检索、可从玩法对象直达的图册。玩家应在两次操作内到达所需规则；未发现的卡牌信息不得通过搜索、焦点文本或无障碍描述泄露。

页面流：

```text
指南首页
├─ 3分钟上手 ─ 六步视觉导览 ─ 详细规则
├─ 规则图鉴 ─ 主题目录 ─ 条目 ─ 关联条目
├─ 探索图鉴 ─ 类型分页 ─ 卡位 ─ 条目详情
├─ 继续阅读（有记录时）
└─ 本局相关（从对局打开时）
```

## 信息层级

- 一级：模式入口、章节标题、当前核心结论。
- 二级：视觉示意、三条以内摘要、进度与相关条目。
- 三级：详细裁定、术语和例外，仅在玩家主动展开后出现。
- 卡牌百科直接读取正式 Resource；指南源稿只描述系统规则。

## 焦点与输入

- 打开后焦点落在当前内容的第一个有效操作；关闭后恢复入口控件。
- `Esc`、`ui_cancel` 返回上一层；在首页再次取消才关闭指南。
- `F1` 和手柄 View/Back 从对局打开；指南已打开时再次按下等同关闭。
- 左侧目录使用上下导航；内容操作使用上下导航；页脚前后页使用左右导航。
- 搜索仅包含公开规则和已发现条目。手柄无需输入文字，可用分类签与索引浏览。
- 模态打开期间背景控件失去焦点，鼠标事件由全屏遮罩截断。

## 状态

- `Hover`：米金底轻微提亮。
- `Focus`：白金双描边；不能只改变颜色。
- `Selected`：章节签前移并显示印记。
- `Locked`：仅显示统一牌背和“未发现”，不设置真实名称 Tooltip。
- `Discovered`：原卡位翻面；首次发现不反复弹提示。

## 响应式规则

- `>= 1500px` 且宽高比较大：左侧章节导航、中央内容、右侧可选关联栏。
- 4:3 或较窄窗口：左侧导航改为抽屉，内容单列，页脚固定在安全区内。
- 媒体槽保持比例并限制最大高度；正文只纵向滚动，不出现横向滚动条。
- `2560×1600`、`1920×1080`、`1280×720`、`2048×1536`、`3440×1440` 共用容器布局。
- 字体放大时先让摘要换行，再压缩媒体槽；不得遮挡关闭和导航按钮。

## 动效

- 页面进入：0.2 秒淡入并上移 18px；新动效开始前取消旧 Tween。
- 牌面发现：牌背淡出、牌面淡入；不依赖真实 3D 翻转。
- 演示只呈现已经确定的规则结果，跳过动效不得跳过规则或消耗额外随机数。
- 开启减少动态效果时直接写入最终状态。

## 对局内暂停所有权

- 打开指南取得 `TurnManager.RESUME_REMAINING` 模态租约。
- 若存在活动选择，同时取得 `InteractionCoordinator` 挂起租约；倒计时保留原剩余值。
- 关闭时先确认会话、回合和交互 ID，再释放挂起；不得恢复旧局或旧回合协程。
- 终局、返回主菜单或场景切换直接取消指南和租约，不恢复后台操作。

## 可替换媒体槽

当前纵向原型使用现有地图、卡背、牌面和职业立绘。媒体槽只约定用途和比例，不把装饰边框写死；后续美术可以替换标题字体、纸张、章节签、印章和插图，而不改页面结构。
