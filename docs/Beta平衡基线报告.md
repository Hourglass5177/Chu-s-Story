## 自动标记

- 某一结束原因占比超过 80%，说明自动对局仍高度集中于同一种结束方式。
- 下列事件在样本不少于 20 时，无事发生率超过 40%：太旧换新、故地重游、同台竞技、市集淘珍、国宝护航、以食会友、艺藏互换、鉴往知来、紧急避险、展艺共研、薪火相传。

这些事件中有些本来就依赖手牌、库存、位置或目标条件，因此高无效果率不必然代表缺陷；下一步应先区分“合理条件不足”和“模拟策略未主动创造条件”。

## 后续验证建议

1. 用真人 2、3、6 人局核对首位淘汰轮次、结束原因和后排座位体验。
2. 静态计算六个出生地区到事件、商店、风景、非遗与研究所的最短成本分布，验证地区差异是否来自地图结构。
3. 对高无效果率事件拆分原因码，区分无合法目标、库存为空、成本不足和玩家主动放弃。
4. 在真人数据与自动数据指向一致前，不调整职业、地图或经济数值。
