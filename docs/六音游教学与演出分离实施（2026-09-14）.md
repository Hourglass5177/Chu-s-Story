# 六音游教学与演出分离：本轮实施记录

本轮承接“音游优先、整景与动作并行”计划。当前完成的是教学、演出时间线、审查工具和三项后景人物的增量；**未完成整份十五关计划，也未把旧固定切句改称已听审的完整乐句**。不制作美术 ZIP，不录真实麦克风。

## 已实施

### 六关教学与演出

- 六关谱面资源升级为版本 3，六音游教学完成记录升级为版本 5；其余九关教学版本不变。任务编号、正式成本、尝试、退出与退款不变。
- 新增 17 个教学步骤，分别训练丝弦单拨／双拨／停顿，撒叶儿嗬左右脚／重复／停步，花鼓短声／长声／收声休止，汉剧选侧／保持，提琴短弓／两向长弓，鼓盆基础句／停顿句。
- 每步音频从该关实际正式混音导出，保留原混音、切入切出毫秒与 SHA-256；不再统一使用另一段蜂鸣教学。练习复用本步的声音、动作和判定，连续两次失败重播当前示范。
- 音乐判定与伙伴演出分开存储。`choreography` 记录演员、动作、时间、可选关联判定；独立乐师、主唱、鼓手可以在没有计分事件的时段表演。丝弦两位伙伴不再同步循环同一动作。
- 起点、保持、收尾和休止的辅助图形保留；局部增加“按住／松开／停手”。教学顶条区分“示范／练手”，示范期间不再隐藏当前动作说明。
- 动作在自己的开始时刻取第一帧；预备、收势切换和重复动作不再从全局循环的任意帧开始。暂停时不推进动作时间。
- 实际短音频回放暴露了结束位置回落：音频已到末尾，却等待不到教学精确终点并误报中断。现在只在音轨末尾、全部判定窗口结束后接受片尾缓冲余量；中途断音仍走技术错误，评分窗口不变。
- 实际动态画面暴露了局部字体资源过早释放：每次绘制临时复制字体，绘制命令执行时字形纹理已失效，显示成色块。局部提示持有同一字体资源，重新渲染检查；顶部 Host 字体没有更换。

实现入口为 `tools/build_rhythm_lessons_v3.py`，导出在 `InheritanceTasks/Audio/rhythm-v3/`。`baseline-v2/` 归档旧输入，重复构建不会在新混音上叠加剪辑。正式混音音频与计分事件本轮保持原值。

### 后景演员候选

花鼓戏、汉剧、提琴戏的独立后景演员按已有服装与角色参考重新生成，靠近博主的卡通比例，保留完整人物和器物；原件留存。提琴后景与封面按新帧宽高比显示，避免把脸压窄。

花鼓戏第一稿为 RGB 棋盘格，已拒绝并经 imagegen 改成技术绿底后接入。三套资产的源图、导出、整景、原速动作、六身份和用户意见分别记录在各关 `source/*/npcs-r4-provenance.json`。四个或八个关键姿势仍不等于连续动作已经完善。

提琴前景另生成 r6、r7 两次候选。r6 的弓长随手臂明显变化；r7 仍有弓尖越过帧框、姿势间隔不均匀的问题。两套均没有替换正式前景，记录在 `source/ti_qin_xi/bow-revision-r6-r7.json`。当前五帧保持及反向倒放的问题仍待解决，不能标记长弓整改完成。
