# 传承任务原型素材替换清单

Beta 0.5.0 先用 Godot 绘制节点与简单几何图形验证玩法。本文列出后续美术、音频和文化审校的替换入口。替换素材只能改变表现，不能改变碰撞区、判定时序或任务规则。

## 一、共用规格

项目基准视口为 2560×1600，任务舞台按 16:10 安全区设计。美术交付建议使用以下规格：

| 用途 | 目标规格 | 说明 |
| --- | --- | --- |
| 任务舞台背景 | 1600×1000，PNG 或无损 WebP | 四边保留 8% 安全区，允许等比缩放与裁切 |
| 图鉴缩略图 | 640×400，PNG 或 WebP | 不包含任务名和按钮文字 |
| 角色、器物与前景 | SVG，或最长边 512/1024 的透明 PNG | 交付独立图层，不把判定线烘进图片 |
| 轨迹、判定带与提示符 | SVG 或可九宫格缩放 PNG | 颜色以外还需有形状或位置差异 |
| 成功演出 | 2—3 秒分层素材 | 可被“减少动态效果”直接切到终态 |

所有文字继续由 Godot 控件绘制。美术底图不得写死倒计时、分数、按键名称或失败原因。正式素材进入工程前，需要记录来源、作者、授权状态和文化审校人。

## 四、替换流程

1. 美术或音频提交时，先在本清单中补路径、作者、来源、许可证和审校状态。
2. 以新文件加入版本化目录，不覆盖白模或原始授权媒体。
3. 在任务场景中只替换展示节点，保留原碰撞区、计时、判定阈值与输入路径。
4. 分别检查 16:9、16:10、4:3 和超宽屏，确认核心判定物没有被裁切。
5. 打开“减少动态效果”验证终态仍完整，声音任务在静音时仍有足够视觉提示。
6. 逐项完成文化审校和授权复核后，才能把白模状态改为“正式素材”。
