# 传承小游戏像素重构与验收记录

本轮按用户确认的十五关逐项方案实施。当前记录以工程资源、实际运行与本轮测试为依据；上一轮七关玩法认可继续保留，新像素画面和重做关的玩家体验尚未获得用户验收。

## 玩法与界面

- 十五关均挂接 `HeritageTaskPresentation`，包含独立背景、六位博主主题动作图集、舞台场景和封面；故事额外提供四幕共12张关键姿势分镜与四张专用缩略图。
- `HeritageTaskRunContext.avatar_id` 保存正式玩家职业外观快照；练习图鉴选择六位博主，最近选择写入独立小游戏设置，不修改职业或发现记录。
- 木壳电视宿主承载准备、教学、挑战、暂停、结果和技术错误。真实Godot控件负责按钮、焦点和输入；木纹、网罩与旋钮属于表现层。500×300局部像素视口对应1000×600逻辑舞台，中文UI独立显示。
- 炼丹、兴山、糖塑、鼓盆歌、剪纸、神舟和黄梅戏保留主要操作与评分。黄梅戏未进行本次真实麦克风录制。
- 鼓盆歌、剪纸、神舟新增可重学的可操作教学：示范、完成实际动作、倒数后进入正式挑战。练手耗时不进入正式25秒；挑战重置练手状态。黄梅戏必要的视频示范保持。
- 神农保留原物理参数和起跳容错，增加长短跳、低顶、石障组合；董永以整车进入桥区计算速度风险，刹车优先。
- 下堡坪使用24秒四幕阅读与30秒排序，阅读可暂停；取消TTS依赖，首次错误给出一处提示，保留第二次提交与结果重播。
- 五音乐关分别提供真实原声教学和独立舞台。汉剧改为追光切换；短长弓、单双拨、舞步与短长应答分别反馈。长按权重30%起点、30%保持、40%收尾；休止贡献最多20%，空击累计扣分。
- 正式成本、尝试、解锁、退出先结算后返回、技术错误退款沿用原事务。暂停、失焦和确认退出冻结音乐及判定，恢复倒数后进行中的长按可短暂续接。

## 资产与编辑方式

全部新资产在 `InheritanceTasks/Art/Pixel/v1/`。`source/` 保留原始生成PNG与被替换版本，`runtime/` 是去底、切片与统一尺寸后的运行图，`resources/` 保存Godot动画和表现资源。`presentation-manifest.json` 是可编辑的十五关索引，源图提示词和生成来源分别记录在根级及三类 `*-art-generation-log.json`。

`tools/build_pixel_assets.py` 负责通用像素归一化；音乐、动作和工艺有各自切片脚本，保留需要的局部锚点。`tools/build_pixel_resources.py` 从索引生成 `.tres`。修改动作图集后必须同时检查透明边缘、帧间比例、六位身份、手与器物接触及实际运行画面，不能只把加载成功记为完成。

源图、设计板和测试截图不进入游戏发布包。原桌游角色、卡牌、地图、视频原件和先前媒体派生版本保留。精简美术需求书已经将十五关全套素材及UI/UX移出美术老师工作量。

## 仍需素材与听审

1. 荆州鼓盆歌：原声演唱或传习，最好持续看清鼓板与双手。用于器物、握法、示范和玩家反馈采样；演唱可用于开场与收句。
2. 西塞神舟会：神舟全貌、侧面或斜侧面、送舟入江。用于核对楼台、船身比例、装饰层次和顺流姿态。
3. 鄂州雕花剪纸：刻刀、手、纸、蜡盘近景与完整成品。用于核对工具、手势和镂空结果。
4. 撒叶儿嗬连续全身与提琴运弓近景有助于动作校对。花鼓戏继续复用已有《站花墙》，没有把编排缺陷归咎于素材不足。

五项音乐的全段候选谱面尚需逐句听审：丝弦单双拨交接、撒叶儿嗬左右及停顿、花鼓戏短长应答与收声、汉剧跨台与停留、提琴短长弓起收。能量峰只辅助定位，不作为已经确认真实唱句、帮腔、声腔或弓法的证据。

用户继续提供已授权完整视频即可；抽帧、选段、音频提取与台账由开发侧处理。

收尾修复了暂停设置不能即时关闭音乐提示、减少动态尚未接入像素环境循环，以及神舟极端偏航时船身出框。减少动态只冻结装饰循环，必要的手、脚与预备动作保持；神舟仅修改船与航道的共同显示投影，惯性、输入和评分未改。

新版本的真人可理解性、操作手感与美术满意度仍等待用户逐关试玩。上一轮七关玩法认可继续作为边界，不转写为对本轮全部新画面的验收。
