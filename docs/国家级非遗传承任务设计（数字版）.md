# 《楚物志》国家级非遗传承任务设计（数字版）

> 本文记录 Beta 0.5.0 已确认的传承规则与 15 项小游戏设计。旧版《国家级非遗互动任务设计.pdf》不作为数字版任务依据；具体操作阈值可以在玩法测试后校准，但不得改变本章列明的任务目标、结算规则和文化边界。

## 一、设计目标

玩家抽到国家级非遗牌时，只是“遇见”了这项非遗。要让它真正进入自己的收藏与计分体系，还需要完成一次与其内容有关的传承任务。

传承任务首先得是一段好玩的游戏，其次才是一段文化介绍。它不该把几个文化名词拼成选择题，也不该为了显得“内容丰富”，在几十秒里塞进排序、节奏、拼图和问答四套操作。玩家只需要做一件事：刻出一朵花、守住一炉火、架过一道山崖、跟唱一小段唱腔。文化信息由动作、画面和结果自然带出来，不在游玩中途停下来考试。

本文用四条标准检查每项任务：

1. **一个核心动作。** 一局只练一个动词，不在中途换玩法。
2. **三秒看懂。** 一句目标和一次动态示范足以说明操作。
3. **二十多秒有起伏。** 既不会刚明白就结束，也不会拖成一个独立关卡。
4. **完成时值得一看。** 剪纸展开、糖塑成形、合奏加入、故事传开，这一刻既是奖励，也是玩家记住这项非遗的地方。

“贴合文化”不等于把资料里出现的所有知识都做成机关。一个动作只要抓准了这项非遗最鲜明、最自然的部分，就比三道牵强附会的题更有力量。

## 二、已确认的通用规则

### 1. 获得与锁定

- 玩家在非遗点抽牌时，有概率抽到该地区的国家级非遗牌。
- 国家级非遗牌进入玩家手牌后，默认处于“未传承”状态。
- 未传承时，牌面分数位置显示“？”，实际按 0 分计算。
- 未传承的牌不参与基础分、类别组合、地域组合、持牌数量、成就和事件条件。规则判定时，这张牌等同于尚未进入玩家的有效收藏。
- 玩家仍可打开这张牌的文化介绍，并从详情弹窗进入传承任务。
- 国家级非遗不能出售、购买、赠送、偷取、交换或转移，也不会进入研究所。若被“弃任意手牌”类效果弃掉，该牌直接离开本局。

### 2. 发起任务

- 任务入口名称固定为“传承任务”。
- 只有持有者在自己的行动阶段可以发起。
- 每次发起先消耗 1 点精力；精力不足时不能开始。
- 同一张国家级非遗牌在每个行动阶段最多尝试一次。
- 挑战失败后，本回合不能再次挑战该牌，必须等到自己的下一个行动阶段。
- 玩家同时持有多张未传承国家级非遗牌时，各牌的尝试次数分别计算；只要精力足够，本回合可以分别挑战。
- 主动退出与普通失败一样，保留已经支付的精力和本行动阶段的尝试记录。
- 场景无法载入、麦克风不可用、权限被拒绝、评分模型异常等技术故障会退还精力，并撤销本次尝试记录。

### 3. 成功与失败

- 挑战成功后，该牌永久变为“已传承”。
- 解锁后恢复 5 点基础分，并从此正常参与地域、类别、持牌数量、成就和事件条件。
- 解锁只作用于这一张牌，不会顺带解锁同名任务或其他国家级非遗牌。
- 挑战失败不丢牌，也不追加惩罚；已经消耗的 1 点精力和本回合尝试次数不返还。
- 成功后立即刷新手牌分数与计分详情；是否达到胜利条件仍沿用现有规则，在完整回合结束时统一判断。
- 第一次真正进入小游戏场景时，对应任务永久解锁到主菜单的小游戏图鉴。成功、失败和主动退出都会解锁，技术故障发生在场景准备完成前则不会解锁。
- 图鉴重玩使用练习模式，不改变当前对局、计分、资源、成就或真实发现进度。

## 三、任务共通规格

以下规格适用于全部传承任务：

- 一局的实际操作时间以 **20—30 秒** 为主；黄梅戏需要连续试听和录唱两句，完整流程允许达到 35—45 秒。
- 任务封面只写一句目标。首次进入时播放约 2—3 秒的无惩罚示范，之后立即开始。
- 每项任务只使用一个连续动作，或一个动作的重复：按住、松开、拖动、点击、左右切换、按顺序复现。
- 小失误应能马上补救。除非玩法本身需要风险判断，否则不因一次失误立即判负。
- 初次接触时的目标通过率建议控制在约 65%—75%。任务需要玩家认真操作，但不要求先查资料或背答案。
- 成功条件只判断“是否掌握”，不追加铜、银、金评价，也不根据高分多给奖励。
- 任务期间暂停行动阶段倒计时和普通地图操作；结束后回到原详情弹窗或手牌界面。
- 鼠标、键盘和单手柄都必须能完成。声音任务需要同步视觉提示；只有黄梅戏以麦克风演唱为主要玩法。
- 正式音频、动作、纹样、服饰和仪式画面必须使用授权素材，或在保护单位、传承人及相关专业人员指导下制作。
- 表现反馈以 2—3 层为宜：核心动作反馈、进度反馈、完成演出。不要用持续震屏、大量粒子或长动画盖住操作。

## 五、任务详细设计

### 1. 鄂州雕花剪纸｜一刀成花

**所属地区：** 鄂州

**当前游戏内描述（原文）：**

> 鄂州雕花剪纸是湖北地方民俗的重要载体，光绪年间有记载。作品构图匀称，风格细腻，实用与装饰性兼具。新中国成立后，燕矶等地成立互助组，创制两千余种花样。

**为什么选这个动作：** 鄂州雕花剪纸常以刻刀在蜡盘上雕刻叠纸，一次可刻出多张花样；花样也常被用作刺绣底稿。小游戏要让玩家真正“行一回刀”，而不是把它做成泛化的拼图。资料见[鄂州市人民政府《鄂州雕花剪纸》](https://www.ezhou.gov.cn/zjez/ezrw/ezwy/201507/t20150715_45096.html)。

**玩法：** 叠纸铺在蜡盘上，一条连续刻线从起点亮起。玩家按住行刀，沿着略有弯折的安全通道走到终点。纸桥处通道会收窄，需要放慢；偏出通道时刻刀产生阻力并留下浅痕，但不会立刻失败。

鼠标按住拖动；键盘与手柄按住确认键，以方向键或摇杆控制刻刀。键盘和手柄使用更宽的吸附通道，避免自由曲线只对鼠标公平。

**成功条件：** 在 25 秒内走完刻线，关键纸桥没有完全切断，整体偏离长度不超过阈值。

**失败反馈：** 作品仍会展开，断口以淡红轮廓标出，并只提示最主要的问题，例如“纸桥被切断了”。玩家能清楚看到差在哪里，而不是只收到“挑战失败”。

**乐趣回报：** 完成后揭起最上层纸样，下面同时展开数张相同花样；其中一张覆到绣片上，短暂呈现由花样到绣品的变化。

**表现重点：** 使用刻刀、叠纸和蜡盘，不用普通剪刀代替。纹样来自已有牌面、官方展览资料或经授权的传统花样。

### 2. 黄梅戏｜一句入戏

**所属地区：** 黄冈

**当前游戏内描述（原文）：**

> 黄梅戏起源于湖北黄梅，原名采茶戏等，我国五大戏曲剧种之一。清末传入安徽，与当地艺术结合，形成安徽黄梅戏。其主腔属板式变化体，表演载歌载舞，质朴细致。黄梅戏角色行当体制丰富，演员可兼扮。

**为什么选这个动作：** 黄梅戏最直接、也最有感染力的入口就是唱腔。让玩家真的听两句、唱两句，比在花腔、彩腔、主调之间做一道没有经验基础的选择题更有趣，也更诚实。资料见[湖北省文化和旅游厅《黄梅戏》](https://wlt.hubei.gov.cn/bmdt/ztzl/zshb/201912/t20191226_1799503.shtml)。

**玩法：**

1. 完整播放授权素材中的两句唱腔，同时显示字幕、当前句和简洁音高轨迹：

   > 为救李郎离家园<br>
   > 谁料皇榜中状元

2. 示范结束后进行倒数。倒数期间停止原唱回放，避免扬声器声音被麦克风收录。
3. 玩家连续录唱两句，中途不分成两次录音。界面始终显示歌词与当前句，并用克制的节拍提示标出起句和句间衔接。
4. 录音结束后，本地演唱评分模块分别比较两句，再给出综合结果。

整局只有“听一遍，再唱一遍”这一个循环，不加腔系选择、角色判断或第二段节奏游戏。示范、倒数、连续录唱和评分合计控制在 35—45 秒。

**评分口径：**

- 有效发声完整度占 10%，可移调的音高轮廓占 55%，节奏与句间衔接占 35%。
- 允许玩家整体升调或降调，系统先按其舒适音区对齐，再比较音程关系，避免不同声部和嗓音条件天然吃亏。
- 不评价音色、性别、年龄、音量、方言口音，也不要求“像专业演员”。
- 第一版不依靠歌词语音识别打分，防止口音、设备和训练数据偏差盖过真正的旋律表现。
- 两句必须都检测到足够的有效发声，防止只唱一句通过。
- 失败时只指出一个最清楚的问题，例如“第二句起早了”或“结尾音还可以再抬一点”，不显示羞辱性排名。

**成功条件：** 综合分不低于 60，任意一句不得低于 45，并且两句都有足够的有效发声。门槛之后可以用真人样本校准，但三项评分权重、双句完整要求和不评价音色的口径保持不变。

**技术实现：**

- Godot 可通过 AudioStreamMicrophone 与 AudioEffectRecord 录制麦克风，项目需要启用音频输入并处理系统权限。见[Godot AudioEffectRecord 官方文档](https://docs.godotengine.org/en/stable/classes/class_audioeffectrecord.html)。
- Windows x86_64 原型使用本地 ONNX Runtime CPU 和轻量 CREPE 音高模型。模型只加载一次，推理放在工作线程中，避免阻塞游戏主线程。CREPE 的用途是从单声部录音估计基频，见[CREPE 论文](https://arxiv.org/abs/1802.06182)。
- 评分器使用可替换接口。其他平台没有对应适配器时按技术故障退出，不切换为另一套传承任务。
- 录音只保存在内存中，结算或中断后立即释放，不上传、不写入存档，也不进入遥测。
- 没有麦克风、权限被拒绝、有效发声不足以判断或模型异常都属于技术故障，退还 1 点精力并撤销本行动阶段的尝试记录。
- 授权原片固定保存在 `arts/非遗媒体资源/黄梅戏-女驸马.mp4`。引擎使用的派生视频、音频和参考曲线必须单独保存，并在媒体记录中写明哈希、截取范围与用途，不覆盖原文件。

**乐趣回报：** 玩家曲线与参考曲线在舞台上逐渐重合，第二句接上时，伴奏和灯光一起落到收束拍。成功不是一句冷冰冰的“评分通过”，而是让玩家听见自己确实把这两句接了起来。

**表现重点：** 正式唱句必须取得授权，或由专业人员指导录制。不要用普通流行旋律配戏曲乐器冒充黄梅戏，也不要把玩家的录音保存为收藏或在多人间回放，除非玩家主动选择。

### 3. 西塞神舟会｜送舟入江

**所属地区：** 黄石

**当前游戏内描述（原文）：**

> 西塞神舟会是黄石市的传统端午盛会，包括制作神舟、唱戏、巡游、送神舟等仪式，历时40天，是目前国内端午节时间较长的祈福活动，已有千年历史，群众基础深厚，传承不息。

**为什么选这个动作：** 西塞神舟会从扎制、开光、唱戏、巡游和守夜延续到送神舟入江，重点不是龙舟竞速。小游戏只取最后的“送舟”，把仪式与常见赛艇玩法分开。资料见[湖北省非物质文化遗产保护中心《端午节（西塞神舟会）》](https://wlt.hubei.gov.cn/hbsfwzwhycw/bhcc/fydt/hss/202005/t20200525_2295690.shtml)。

**玩法：** 神舟沿水道缓缓前行，水流不断从不同方向推来。玩家拖动鼠标或推动摇杆，抵消水势，让神舟尽量保持在中央水道。输入不是控制速度，而是控制稳定。

**成功条件：** 约 25 秒后抵达终点，离开安全水道的累计时间没有超过上限。

**失败反馈：** 神舟被水流带到岸边停住，不沉没、不翻覆，也不出现撞船笑料。水面短暂标出最后一次把神舟带偏的流向，提示“顺水势回正”。

**乐趣回报：** 水流由缓到急再归于平稳，玩家在最后几秒会明显感到“稳住了”。抵达后用克制的远景完成送舟，不追加烟花、金币或竞速名次。

**表现重点：** 不把仪式写成“触怒神灵”式惩罚，也不把神舟会等同于端午赛龙舟。

### 4. 夏氏炼丹术及其祖传秘方｜守炉候火

**所属地区：** 荆门（按当前游戏资源目录）

**当前游戏内描述（原文）：**

> 夏氏炼丹术是天门市石河镇唐店村夏氏家族传承的烧炼矿物类药物制作“白降丹”的工艺，传男不传女，家族单传。骨炎灵膏药以白降丹为主药，对骨科疑难重症疗效显著。

**地区说明：** 这张牌归入荆门并不是地区分类错误。湖北省非遗资料记载的申报地区为京山县（今京山市，属荆门），同时记载夏氏家族祖籍位于天门市石河镇唐店村。当前描述把“申报地”和“家族祖籍”压缩在一句话里，容易让人误以为项目申报地区是天门；正式实装前建议把这层关系写清楚。

**为什么选这个动作：** 相关资料把它记录为传统制剂方法，并强调制作过程精细。数字版不应该模拟真实配方、剂量或医疗用途，只抓住“火候需要持续照看”这一种手艺判断。资料见[湖北省非物质文化遗产保护中心《中医传统制剂方法（夏氏炼丹术及其祖传秘方）》](https://wlt.hubei.gov.cn/hbsfwzwhycw/bhcc/fydt/jms/202005/t20200525_2295642.shtml)。

**乐趣回报：** 最佳带会有几次可预判的上扬和回落，玩家能从慌乱追赶逐渐变成提前控火。进度填满时炉火由躁动转为稳定，形成清楚而克制的完成感。

**表现重点：** 界面注明“艺术化工艺演示”。不出现真实矿物名称、配方、剂量、温度、时长或可以照做的烧炼步骤，也不宣称游戏过程能验证现实疗效。“传男不传女”只作为历史背景，不转化为玩家限制或奖励。

**表现重点：** 场景采用传习或正式演出空间，保持庄重。不要用鬼怪、哭丧、摔倒或炫彩爆炸制造笑料。正式唱词、唱腔和鼓点需要授权与专业审核。

### 6. 炎帝神农传说｜踏架登峰

**所属地区：** 神农架

**当前游戏内描述（原文）：**

> 继女娲伏羲之后，不知隔了若干年代，又出现了一个太阳神炎帝。神农架与随州相邻，境内奇峰竞秀，林海苍茫，自古便流传着炎帝神农氏在此搭架采药、疗民疾矢、播种五谷的传说故事。

**为什么选这个动作：** 神农架地区流传着炎帝神农搭架采药的传说，相关叙事提到“架木为梯，以助攀缘”。一段沿木架与山崖向上攀登的平台跳跃关，可以把“架木”“攀缘”和“抵达高处”连成一次完整行动，也比摆放构件更直接、更有运动感。资料见[湖北省非物质文化遗产保护中心《炎帝神农传说》](https://wlt.hubei.gov.cn/hbsfwzwhycw/bhcc/fydt/snjlq/202005/t20200525_2295601.shtml)。

**玩法：** 采用经典横向平台跳跃。玩家控制传说中的神农氏左右移动和跳跃，沿山石、木架与高台不断向上，最终抵达山顶采药台。整段关卡只保留移动与跳跃，不加入攻击、收集材料、搬运木料或解谜。

关卡控制在一个屏幕半到两个屏幕宽，约 25—30 秒：

1. 开头用两段稳定木架让玩家熟悉移动与跳跃。
2. 中段出现断崖、较高平台和会短暂下沉的木架。
3. 后段加入有明显预兆的落石、荆棘或摆动木架；机关只改变跳跃时机，不要求新操作。
4. 最后从移动木架跃上最高平台，抵达艺术化的采药台。

**成功条件：** 倒计时结束前到达终点。

**失败与恢复：** 碰到陷阱或跌出平台后，人物立即从最近的稳定落脚点重新出现，并损失约 2 秒；不设置生命数，也不让一次失误直接结束任务。倒计时结束仍未到达终点，才判定本次传承失败。

**手感要求：** 跳跃必须提供适度的土狼时间、提前输入缓冲和清楚的落点阴影。落石、下沉平台等陷阱至少提前半秒给出声音与视觉预兆。失败重置应在一秒内完成，不能播放冗长受伤动画。

**乐趣回报：** 关卡的高度持续上升，玩家会不断看到更远的山岭。连续越过最后三处平台时，音乐和风声逐步展开；落上终点高台后，角色停步眺望，远景显出层叠山峦与采药台。

**表现重点：** 全程使用“传说中”“相传”等措辞。陷阱采用山石、断木、荆棘和不稳的木架，不加入怪物战斗，也不照搬《超级马里奥》的角色、敌人、砖块、金币或具体关卡元素。植物只作艺术化剪影，不展示真实药名、药效、毒性、食用或采摘方法，也不把自然保护地表现成可以随意采集资源的场所。

**表现重点：** 不要求玩家真的对着麦克风吹气，也不提供真实温度、配方或制作步骤。热糖存在烫伤风险，小游戏不能伪装成现实教程；成品作为传统美术作品展示，而不只是“一颗能吃的糖”。

**当前游戏内描述（原文）：**

> 撒叶儿嗬是清江中游地区土家族非常独特的祭祀歌舞，融合歌、舞、乐，表达豁达通脱的生死观，具有艺术和学术价值。

**为什么选这个动作：** 撒叶儿嗬先由歌师击鼓叫歌，舞者随鼓声应节起舞，常见带切分的六拍律动。玩家只做“随鼓而应”，正好把歌师与舞者的关系变成一个轻量循环。资料见[湖北省非物质文化遗产保护中心《土家族撒叶儿嗬》](https://wlt.hubei.gov.cn/hbsfwzwhycw/bhcc/fydt/ycs/202005/t20200525_2295618.shtml)。

**玩法：** 六拍节奏环循环转动，领舞者会在应和拍做出左、右或正面的动作。玩家在该拍按下对应方向，角色便自动完成经过审核的顺拐、屈膝或悠颤动作。核心始终是“看方向、踩准拍”，不再做动作名称选择题。

**成功条件：** 约十二个应和拍中命中至少九个。

**失败反馈：** 漏拍只让当前脚步与鼓声短暂减弱，不摔倒、不嘲笑；下一拍仍可继续。

**乐趣回报：** 每成功一组，环中的参与者就增加一人，鼓声、歌声和舞步逐渐合在一起。最后不是个人炫技，而是围成完整群舞。

**表现重点：** 场景采用文化传习或排演空间，不出现灵柩、鬼魂、坟墓等猎奇元素，也不把跳丧解释成对死亡的嬉闹。服饰、鼓具与动作需要专业复核。

### 14. 下堡坪民间故事｜口耳相传

**所属地区：** 宜昌

**当前游戏内描述（原文）：**

> 宜昌市夷陵区下堡坪乡流传民间故事两千多个，刘德方等传承人故事量多、内容丰富，作品原生态且具本地特色，文化品位较高，学术和鉴赏价值高。

**为什么选这个动作：** 下堡坪及周边记录有大量民间故事，也有能讲述数百个故事的民间故事家。小游戏不考玩家是否读过其中某一篇，而是让玩家体验“听住，再传下去”。资料见[湖北省非物质文化遗产保护中心《下堡坪民间故事》](https://wlt.hubei.gov.cn/hbsfwzwhycw/bhcc/fydt/ycs/202005/t20200525_2295623.shtml)。

**玩法：** 故事家用一句短旁白依次带出 4—6 个故事图标，随后图标打乱。玩家只需按原顺序点击，把这一小段故事传给下一位听众。共三串，图标数量逐渐增加。

**成功条件：** 三串中至少完整复现两串。

**失败反馈：** 点错后，故事家把正确顺序快速重现一遍，再进入下一串；已经完成的串不会被扣掉。

**乐趣回报：** 每传对一串，故事图标便从上一位讲述者沿声纹传到下一位；最终镜头拉开，围坐的人越来越多。

**表现重点：** 正式图标与旁白必须来自公开出版、保护单位授权或明确可用的采录文本，不能临时生成一则故事再冒充下堡坪民间故事。方言录音必须配字幕，不能用夸张口音制造笑料。

### 15. 兴山民歌｜山谷寻音

**所属地区：** 宜昌

**当前游戏内描述（原文）：**

> 兴山民歌流传于湖北兴山县及其周边，音调奇特，含有“兴山特性三度音程”，其五声音列与商周青铜钟磬音列结构相似，是“荆楚古歌”遗存。常见曲目有《征东》《征西》等，具有重要音乐学和文化学价值。

**为什么选这个动作：** 相关研究资料提到一种介于常规大三度与小三度之间的独特音程。让玩家在连续音高中亲手找到它，比把普通三度答案藏进选择题更能留下听觉印象。资料见[湖北省文化和旅游厅《兴山民歌》](https://wlt.hubei.gov.cn/bmdt/ztzl/zshb/201912/t20191226_1799499.shtml)。

**玩法：** 山谷先响起一个目标短音，并留下声波轮廓。玩家上下拖动一枚回声音珠改变音高；越接近目标，两道波纹越趋重合，声音也由拍频明显变为稳定。松手确认后进入下一音，共三次。

**成功条件：** 三个目标音中至少两个进入允许区间。

**失败反馈：** 偏离时只显示两道波纹尚未重合，并保留目标音供再次试听；结算后让音珠短暂滑到目标位置作对照。

**乐趣回报：** 这是一个“越来越近”的听觉寻宝过程。三个音找到后依次汇入一段真实、获授权的兴山民歌短句。

**表现重点：** 不使用“跑调”“唱不准”“纠错”等文字。任务是在寻找兴山民歌的独特音位，不是把它修正到十二平均律。正式音频必须获得授权或由专业人员指导录制。

## 六、界面、反馈与无障碍

### 1. 牌面状态

- 未传承：分数圆标显示“？”，可增加克制的锁纹或未点亮印章；不要使用“损坏”“残缺”等负面视觉。
- 本回合已失败：任务按钮显示“本回合已尝试”，不可再次点击。
- 已传承：分数圆标恢复为 5，印章点亮，并在详情中保留“已完成”记录。

### 2. 任务入口

详情弹窗中的“传承任务”与介绍内容同层。按钮附近只显示两项必要信息：“消耗1精力”和本回合是否可尝试。

点击后先进入任务封面：任务名、一句目标、一个操作图示和“开始”。首次游玩可播放两三秒动态示范；再次游玩不强迫重看。

### 3. 游玩反馈

- 输入反馈必须即时，但不能遮挡核心判定物。
- 进度只显示玩家当前是否在正确方向上，不反复弹“完美”“太棒了”等空泛大字。
- 成功演出控制在 2—3 秒，随后由“？”翻为“5”，再把实际新增基础分和组合分汇入计分。
- 失败只说明一个最主要、可行动的问题，例如“纸桥被切断了”“火候回落太久”“第二串故事顺序有误”。
- 减少动态效果开启时，取消镜头抖动、弹性放大和多余粒子，但保留判定必需的颜色、位置与声音提示。

### 4. 声音与麦克风

- 所有依赖声音的任务同步提供节拍环、轨迹或波形；色彩之外还需使用位置和形状。
- 黄梅戏录音前必须显示麦克风状态和明确倒数，录音时有持续可见标识。
- 设备缺失、权限被拒绝、输入中断或录音质量无法判定属于技术中断，不写成“玩家失败”。
- 不在后台持续监听，不保存录音，不把玩家声音自动播放给其他玩家。

### 5. 小游戏图鉴

- 入口只出现在从主菜单打开的游戏指南中。局内指南不显示小游戏图鉴，也不能从中进入练习。
- 第一次完成场景准备、真正进入小游戏后，该任务永久解锁。成功、失败或主动退出不影响发现结果。
- 未发现任务只显示统一的“未发现”，不公开非遗名称、任务名称、操作方式或关键词。
- 已发现任务可从图鉴重玩。练习使用独立上下文，不读取或修改对局中的玩家、手牌、精力、分数、成就与尝试次数。
- Debug 构建中，指南打开时可用 `Ctrl+Shift+D` 临时切换开发者视角。开发者视角只在当前进程中显示全部条目，不写入发现存档；局内仍不提供小游戏入口。

## 七、制作与验证顺序

实现时先跑通四个纵向切片，再铺开其余场景：

1. **夏氏炼丹术：** 验证统一任务壳层、单键连续控制、计时、成功与失败回传。
2. **鄂州雕花剪纸：** 验证自由指针、轮廓吸附，以及鼠标、键盘、手柄之间的公平性。
3. **黄梅戏：** 单独做技术原型，先用不同性别、音域、麦克风和环境噪声的真人录音校准，再决定模型和通过线。
4. **下堡坪民间故事：** 验证移动选框、顺序输入和授权内容数据结构。

四类输入跑通后，再按相近技术复用：

- 单键连续控制：炼丹、糖塑、花鼓戏。
- 指针或摇杆跟随：剪纸、神舟会、提琴戏、老河口丝弦、兴山民歌。
- 节奏与短序列：鼓盆歌、汉剧、撒叶儿嗬、下堡坪民间故事。
- 独立录音评分：黄梅戏。
- 短程平台跳跃：炎帝神农传说。
- 定时输入：董永传说。

十五项可以共用任务壳层、输入提示、结果页、暂停与会话安全逻辑，但核心玩法场景彼此独立。不要用一个巨型脚本通过十五个分支承载全部任务。

## 九、已确认边界

1. 普通任务以 20—30 秒为主；黄梅戏完整流程为 35—45 秒。
2. 黄梅戏没有无麦克风替代任务。设备、权限、输入或模型异常按技术故障处理，返还成本和次数。
