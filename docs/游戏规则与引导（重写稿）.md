# 《楚物志》数字版游戏规则与引导（重写稿）

> 本文是游戏内数字版规则与引导的唯一正文源。正文按第一次接触《楚物志》的玩家来写；方括号【】中的内容是后续界面制作与配图说明，不属于最终展示给玩家的规则文字。

荆楚大地，山水相连，技艺相传。

在《楚物志》中，你将扮演一名非遗博主，从湖北的一座城市启程。骰子决定这一回合能走多远，精力决定这条路是否走得动；沿途的非遗、风景、食物与事件，又会悄悄改变下一段旅程。你可以专心收藏，也可以经营积分点、抢先完成成就，或等一个合适的时机打出手里的牌。

旅程结束时，所有人的收藏与成就都会化为分数。即使有人早早离场，冠军也要等最后一次计分之后才能确定。

## 一、快速上手

### 1. 基本目标

作为非遗传承人，探索湖北地图，收集非遗、经营资源、提高分数，最终总分最高者获胜。

#### 旅程从脚下开始

在《楚物志》中，你将扮演不同类别的博主，从湖北的一座城市出发。一路经过非遗点、风景、商店、事件与研究所，学习和收集各地非遗，并将非遗牌组合得到更高的分数。

- 玩家按顺序轮流进行回合。
- 回合结束时，若有玩家分数达预设目标，或淘汰人数达2人，则游戏结束。
- 游戏结束时，计算全体玩家分数，按最终分数排名。也就是说，淘汰不代表最终一定不会获胜！

【配图：使用真实对局中的非遗格悬浮信息截图，画面必须直接显示“地域 · 编号 · 地形 · 非遗”和精力消耗。不要自行添加起点、终点或路线标记，也不要把五龙河、千年银杏谷等风景格误标成非遗点。】

### 2. 成为非物质文化遗产传承人

非遗牌是《楚物志》的核心资源，也是总分最主要的来源。武汉、恩施、随州、十堰、咸宁……地图上的非遗点分别属于湖北不同地区；到达非遗点后，可以在行动阶段消耗1点精力，学习并获得该地区的一张非遗牌。新牌会收入右侧手牌区，同时打开对应的文化介绍。

每张非遗牌都包含四项与游戏有关的信息：

- **地区：** 决定这张牌从哪里获得，也用于计算同城收藏和集齐城市的分数。
- **类别：** 当前共有戏曲表演、民间音乐、手工技艺、神话传说、节日庆典、武术拳法和国家级非遗七类。类别既影响组合计分，也决定牌的基本效果。
- **基础分：** 只要牌仍在手中，它的基础分就会计入总分。基础分为0的牌仍可组成类别和地域奖励。
- **牌面效果：** 有些牌需要在自己的移动阶段或行动阶段使用，有些牌用来响应其他玩家，还有些牌在获得或持有时自动生效。

收集的牌越多，不一定就比别人分数高。把同一类别收成一组、凑齐更多不同类别、集中收集同一城市，或者集齐某个类别与城市，都会带来额外分数。同一张非遗牌可以同时参与几种组合。

一部分非遗牌还能直接参与行动。使用、出售、赠送或交换都会让它离开原来的手牌，分数随之重新计算。因此，一张当前能发动的牌，未必应该立刻使用；它也许正维持着一组重要的搭配。

国家级非遗具有极高的单张分数，但不能使用、卖出或被夺走，也没有特殊效果。

【配图：并列展示三张来自不同地区的真实非遗牌，使用武汉“汉绣”、潜江“潜江民歌”和十堰“武当武术”。三张牌等高排布，牌名、地区边框、类别圆标、分数圆标和牌面效果必须直接可读；窄屏改为单列。】

### 3. 局内资源

积分点是购买食物、交换非遗牌的通货；精力支撑移动与行动；非遗牌和成就牌累积总分。

#### 积分点让你有选择，精力让你走得更远

玩家开局拥有500积分点和6点精力（上限为12）。积分点可以买食物、从研究所购入非遗；精力会在移动、收集非遗和打工时消耗。

- 食物牌：回复精力，或提供各种各样的奇特功能。
- 非遗牌：有基础分数和组合分数，且每种非遗牌都有自己的特殊效果。
- 事件牌：各种随机事件，带来惊喜或是惊吓。
- 成就牌：达成一定目标时自动获得，提供额外分数加成。全局唯一，先到先得。

非遗牌的交易在非遗研究所进行。

积分点和分数是两回事。积分点可以花，分数决定排名；再富有的玩家，也要靠非遗收藏与成就赢下比赛。

【配图：初始积分点与精力，以及非遗牌和成就牌。积分点与精力只使用一张干净的真实 HUD 近景，不截入职业名称、立绘或人物脚部；非遗牌和成就牌保持足够大，牌名与牌背能直接辨认。】

### 4. 我的回合，抽卡！

玩家每回合依次执行准备阶段->掷骰子->移动阶段->行动阶段->结束阶段。

#### 准备 → 掷骰 → 移动 → 行动 → 结束

准备阶段处理回合开始效果；随后投两枚六面骰，得到本回合的基础移动步数。移动阶段可以分几次选择终点，直到主动结束或步数用完。进入行动阶段后，风景与事件会先自动处理；非遗、商店、打工和研究所则开放对应按钮，由你决定是否操作。

- 准备阶段：进入回合，部分效果在此阶段触发；
- 掷骰子：玩家掷2枚六面骰子，点数之和为移动阶段的基准最大可移动步数；
- 移动阶段：玩家可以点选地图高亮部分，消耗精力移动；
- 行动阶段：执行到达地块效果，并可使用食物牌和部分非遗牌等；
- 结束阶段：结束回合，部分效果在此阶段触发。

【配图：使用五段式横向流程图，五段分别放“准备、2D6、蓝色路径、地点按钮、交接玩家”的真实 UI 局部截图。整图宽高比约 3:1，置于流程标题后。不要用五个同样大小的纯文字方框；掷骰、移动和行动三段应占较大面积，因为它们是玩家真正操作的部分。】

### 5. 移动阶段：千里之行，始于足下

骰子结果决定移动阶段最大可移动步数，精力决定你到底能走多远。蓝色格子是当前可到达地块。

#### 先看蓝色终点，再看路径消耗

地块分为三种地形，不同地形路过消耗的精力不同：平原（1点）、山地（2点）、湖泊（2点）。

- 点击蓝色高亮地块后，玩家棋子沿系统选出的路线移动，并扣除消耗精力。
- 同一终点有多条走法时，优先选择精力消耗最低的路线；仍相同时，选择步数更少的路线。
- 移动后若仍有步数与精力，地图会从新位置重新显示可达格子，你可以继续移动。

#### 一个简单例子

假设你掷出8点，只剩5点精力。某个终点虽然只要走6步，但路径消耗6点精力，它仍然不可达。

【配图：直接使用真实移动阶段的原始截图，保留玩家棋子与蓝色可达地块，不额外绘制“起”“终”、路线或方向箭头。玩家当前所在格就是移动起点。】

### 6. 行动阶段：落子无悔

行动阶段先处理落点格子的特殊效果，再自由行动。

#### 落点格子决定这一回合做什么

根据到达地块格子的不同，玩家会触发不同的效果或者可以进行不同的行动：

- 非遗：可以消耗1点精力收集该地区非遗牌。
- 打工：可以消耗1点精力打工获得积分点，同一个打工点最多连续打工3次，之后不可再于此处打工。
- 商店：可以购买具有各种效果的食物牌。
- 风景：自动触发，欣赏美景，首次到达回复3点精力。
- 事件：自动触发，抽取一张事件牌并执行其效果。
- 研究所：也称交易所，可以在此处售出非遗牌，或购买研究所中的非遗牌。

【配图：行动阶段的可用按钮。保留真实落点、信息栏以及行动、食物、结束按钮，让玩家直接看懂到达后从哪里操作。】

#### 有些效果会把你送到别处

事件传送、玩家换位等特殊移动，默认只改变位置，不把目标格当作一次到达，也不会触发那里的特殊格子效果。只有牌面明确要求结算目标格时，才会例外执行。

## 一、开始一局

### 1. 选择游戏模式

从首页进入“开始游戏”，选择“本地游戏”。网络游戏与教学模式目前保留入口，尚未开放。

本地游戏支持1至6个席位。当前版本的电脑席位还没有接入自动决策，即使在人数页设置了电脑玩家，仍会像其他席位一样由本地玩家依次操作。

【配图：模式选择弹窗与人数设置弹窗各一张，左右并列，占正文全宽。只截取弹窗本体，不保留后方首页背景；突出“本地游戏”和总人数限制。】

### 2. 决定谁来旅行

每个席位依次设置名字、职业和起点。

- 职业不能重复。六种职业分别擅长食物、抽牌、探索、经商、风景和打工。
- 起点不能重复。当前可选起点为十堰、随州、孝感、黄冈、荆州与恩施。
- 名字可以相同；留空时会使用P1、P2等作为默认名。
- 全部设置完成后，在阵容总览中检查并确认。

选择职业时，职业卡会直接显示能力。六种职业的区别如下：

| 职业   | 职业效果                                    |
| ---- | --------------------------------------- |
| 美食博主 | 每个自己的回合最多享用3张食物。                        |
| 魔术博主 | 抽取事件或在非遗点收集时，查看牌堆顶最多3张，选择1张，并排列其余牌的顺序。  |
| 探险博主 | 准备阶段和结束阶段各可免费移动到1个相邻空格。                 |
| 商业博主 | 开局额外获得500积分点；研究所购买非遗半价；每次光临食物商店可免费刷新1次。 |
| 旅行博主 | 路过风景格时少消耗1点精力；到达风景格后，在行动阶段获得250积分点。     |
| 生活博主 | 打工不消耗精力。                                |

选中职业卡后，右侧会显示更完整的能力说明。被其他玩家占用的职业仍可查看，但不能重复选择。

目标分数可设为15、20、25或30分，默认20分。

【配图：选角页使用一张完整界面图，阵容总览使用一张完整界面图，上下排列。职业卡与人物立绘必须占画面主体；出生地区只显示简洁地名。正式截图不得出现“真人”标签，只有电脑席位标“AI”。】

### 3. 初始状态

每名玩家游戏开始时默认拥有6点精力（上限12点）和500点积分点，作为起始资源。

P1固定先手，之后按P2、P3……的顺序轮流行动。玩家被淘汰后，后续回合会跳过该玩家。

【配图：用一张玩家信息区近景解释“500积分点、6/12精力、0分”。从正常对局的左侧HUD原尺寸裁切。宽屏采用“初始状态表格＋HUD近景”双栏，HUD约占内容区35%；窄屏把HUD移到表格下方并放大到可读。不要只摆一张脱离界面的积分点素材。】

## 三、一个完整回合

每个回合依次经过准备、掷骰、移动、行动和结束五个阶段。

### 1. 准备阶段

准备阶段处理“回合开始时”生效的效果，并重置本回合的使用次数，例如食物享用次数与非遗收集次数。

某些食物会在未来几个回合的准备阶段恢复精力。效果生效时，信息栏会写出食物名称和实际恢复量。

### 2. 掷骰阶段

玩家投两枚六面骰，两枚点数之和是本回合的基础移动步数，结果必定在2至12点之间。

食物、非遗牌或其他状态可能在这个基础上增加步数或令步数翻倍。计算次序为：

1. 两枚骰子的基础点数。
2. 加上永久步数与本阶段临时步数。
3. 若有翻倍效果，最终至多翻倍一次。

多个翻倍效果不会叠成四倍。手工技艺牌与食物共享这个上限。

【配图：两枚六面骰点数相加。用一张专用规则示意展示两枚骰面、加号、点数之和与基础移动步数，不使用无关地图截图。】

### 3. 移动阶段

地图会亮出所有当前可达的终点。点击一个蓝色格子后，系统选择合法路线，棋子移动，并扣除这段路线的步数和精力。

只要还有剩余步数和精力，你可以继续点击新的蓝色终点。也可以提前按“结束”，保留精力并进入行动阶段。棋子移动途中，其他操作会暂时锁定，避免一次点击被重复执行。

手工技艺类非遗牌、畅行无阻等“移动阶段使用”的牌，必须在结束移动前打出。手工技艺牌每个移动阶段最多使用一张。

【配图：移动阶段的蓝色可达终点。使用真实移动阶段画面，蓝色地块、当前棋子和周边路线必须清楚可辨。】

### 4. 行动阶段

行动阶段开始时，先处理本回合最终落点：

- 风景格会自动检查是否首次打卡。
- 事件格会自动公开并结算一张事件牌。
- 非遗点、商店、打工格与研究所会开放对应操作按钮。

地点处理完毕后，玩家仍可以使用当前时机合法的食物、非遗牌或保留事件牌。成功收集非遗不会结束行动阶段；普通事件结算也不会默认跳过剩余行动。只有牌面明确要求“跳过行动阶段”或“结束”时，才会改变流程。

正常的移动阶段和行动阶段各有15秒。事件选择、响应或其他需要思考的弹窗会暂停阶段计时，并使用自己的选择时间。研究所与普通事件结束后，行动阶段重新获得完整15秒；商店、食物背包与游戏指南关闭后，则从打开前的剩余时间继续。

【配图：行动阶段按钮。截取真实行动阶段中的落点与按钮区，不使用准备阶段或纯地图画面代替。】

### 5. 结束阶段

结束阶段处理回合末效果。

随后依次完成：

1. 结算本回合应递减的持续状态与回合计数。
2. 检查当前玩家是否仍为0精力，并处理淘汰前响应。
3. 若玩家最终被淘汰，登记本局累计淘汰人数。
4. 检查游戏是否进入最终结算。
5. 若游戏继续，把回合交给下一名存活玩家。

精力在移动途中降到0不会立刻出局。你仍会进入行动阶段，可以享用食物或使用其他恢复手段。只有完整回合结束时精力仍为0，才会进入淘汰流程。

### 6. 跳过阶段与延迟效果

被食物或事件跳过移动阶段时，玩家仍会正常掷骰，随后跳过本次移动操作；连续打工则会直接越过正常掷骰与移动。被跳过行动阶段时，也不能在该阶段享用食物或使用行动牌。阶段外的防御响应仍可进行，除非效果另有说明。

“未来两次移动阶段”指这个玩家以后真正获得的两次对应阶段，不把已经经过的当前阶段算进去。多个跳过移动的效果按施加顺序排队，每次只消耗一个；尚未轮到的移动加成与减免会留到下次真正可以移动时。

信息栏会写明跳过或延迟生效的来源。

## 四、地图、地形与移动

### 1. 六角格与地域

地图以六角格连接湖北各地。红色边界划分地域，非遗牌也按地域归档。地域不限制玩家通行，却会影响非遗抽取与地域组合计分。

每个格子同时有三类信息：

- 所属地域与编号。
- 地形：平原、山地、湖泊或其他。
- 功能：普通格、非遗、事件、打工、商店、风景、研究所或起点。

把鼠标停在格子上片刻，信息会以“十堰16 · 山地 · 风景（武当山）”的形式出现，下一行显示精力消耗，再下一行说明功能作用。

【配图：使用真实地图格悬浮信息截图，保留玩家棋子、周围地域边界，以及“孝感117 · 平原 · 非遗”“精力消耗：1”等完整提示。】

### 2. 每走一格要付多少精力

移动消耗按“进入哪个格子”计算：

| 地形  | 进入该格的基础消耗 |
| --- | ---------:|
| 平原  | 1精力       |
| 山地  | 2精力       |
| 湖泊  | 2精力       |
| 其他  | 以格子显示为准   |

路线中每一个格子的消耗相加，就是这段移动需要支付的精力。起点本身不重复收费。

武术拳法类非遗会让本移动阶段第一次移动的总消耗减少1；持有多张也不会重复叠加。

食物与事件还可能提供阶段减免、累计减免池或完全免耗。地图亮起的蓝色格子都是真正走得到的终点，点击后会按预览路线扣除精力。

### 3. 步数和精力是两道门槛

终点必须同时满足：

1. 路线步数不超过本阶段剩余步数。
2. 结算全部修正后，路线精力消耗不超过当前可支付精力。
3. 终点未被其他存活玩家占据，也没有被当前状态禁止。
4. 路线不能穿过其他玩家占据的格子，也不能在同一个移动阶段重新走进自己已经经过的格子。

所以，步数很多不等于一定走得远。精力紧张时，平原绕路可能比翻山越湖更划算。

### 4. 路线怎样选

同一终点可能有多条合法路径。系统会比较所有走得通的路线，再按以下顺序选出实际路线：

1. 精力消耗更低的路线优先。
2. 精力相同时，步数更少的路线优先。

移动可以分段进行。每一段完成后，剩余步数、精力与临时减免都会更新，再从新位置计算下一批蓝色终点。已经走过的路线不会因为分段移动而重复获得同一份减免。

【配图：使用真实移动阶段的原始截图，保留当前棋子和蓝色可达地块。不要额外绘制起点、终点或路线，以免把玩家所在格标错。】

### 5. 普通移动与特殊移动

规则里所说的“普通到达”，指玩家在自己的移动阶段点击蓝色终点，完成一段移动，并把那里作为本回合最终落点。

事件、食物或卡牌效果造成的传送与换位，默认不算普通到达：

- 不抽取目标事件格的事件。
- 不打开目标商店或研究所。
- 不自动结算普通风景奖励。
- 不增加打工点或地点的普通访问记录。

只有牌面明确写出“打卡”“学习一次”或其他地点效果，才按那句话额外执行。

若效果明确说明某次特殊移动会保留到达记录，就在行动阶段处理最终落点；没有这句说明的传送与换位仍按默认规则处理。

### 6. 看世界的两种视角

全局视角下，可以按住鼠标左键拖拽地图，滚轮缩放；最小缩放就是完整地图大小。按Alt切换到追踪视角后，镜头围绕当前玩家保持相对追踪，仍可滚轮缩放，但不能自由拖离地图。

从追踪切回全局时，会保留当时看到的位置，不会强行把焦点拉回地图正中。事件演出或特殊移动临时调整镜头后，会尽量恢复演出前的视角、缩放和追踪状态。

## 五、到达之后：地图上的地点

地图共有普通格、非遗点、事件格、打工格、食物商店、风景格、研究所与起点。地点图标告诉你停下来后能做什么，地形则决定走进这一格要花多少精力。两者不要混在一起：一座风景也可能在山地上，一间商店也可能位于平原。

本章所说的“有效到达”，是本回合普通移动后的最终落点，或被牌面明确记作有效到达的特殊移动。留在原地、普通传送与换位，都不会凭空增加一次地点机会。

### 1. 普通格与起点

普通格没有额外操作，但仍要按地形支付移动精力。地图上有六处起点，每名玩家开局选择其中一处；离开之后，起点与普通格一样，不提供反复领取的起步奖励。

没有地点效果不等于没有价值。普通格常是避开山地、绕开其他玩家或为下一回合调整路线的中转点。

### 2. 非遗点

停在非遗点并进入行动阶段后，可以点击“收集非遗”：

1. 支付1点精力。
2. 从该地点所属地域仍有剩余的非遗牌中获得一张。
3. 牌先完成获得动画，再进入右侧对应地域的手牌区。
4. 若是从非遗点学习所得，还会打开这项非遗的介绍。
5. 分数立即按新的手牌重新计算。

每名玩家每回合最多成功收集一张。收集后仍留在行动阶段，可以享用食物、使用卡牌或结束回合。若该地区的非遗已经全部被取走，按钮显示“集罄”，不会支付精力。

节日庆典类非遗从地区牌库抽得时，立即恢复3点精力并获得500积分点，不需要再点一次使用。它以后被出售、买回、赠送、偷取或交换时，只改变持有者，不会重复发放这份奖励。

【配图：获得非遗后的真实详情弹窗。使用正常对局中获得潜江民歌后的完整介绍页，牌面、名称、类别、分数、文化介绍与效果都要可读。】

### 3. 风景格

有效到达风景格后，行动阶段会自动打卡。每位玩家第一次到达某一处风景时：

- 登记这处风景的纪念。
- 恢复3点精力，最多恢复到12。
- 推进与风景数量有关的成就进度。

同一玩家以后再到同一处风景，不再获得普通的3点精力，也不会重复增加打卡数量。

“游目骋怀”和“沉浸体验”会明确带玩家前往风景。若该风景尚未打卡，仍会登记为第一次，但只执行牌面写明的5点或6点精力，不再叠加普通风景的3点。其他普通传送与换位不登记风景打卡。

### 4. 事件格

有效到达事件格后，行动阶段开始时自动公开一张事件牌。玩家不需要再按一次“抽取”。

事件可能立刻改变精力、积分点、位置或手牌，也可能要求选择玩家、卡牌或地图终点。结算期间，行动阶段的倒计时暂停；除非牌面明确改变阶段，事件结束后仍回到行动阶段，并重新获得完整15秒。

同一次到达只触发一张事件。留在原地的下一回合不会再次抽取；离开后再回来，才有新的事件机会。

事件牌用后进入弃牌区，本局不洗回。牌库抽完后，事件格会提示“事件牌已抽完”，随后“无事发生”。

【配图：事件公开并在地图选择终点。先展示“沉浸体验”的真实公开弹窗，再展示返回地图后的蓝色合法终点与操作提示；两张图按顺序纵向显示。】

### 5. 食物商店

有效到达食物商店后，可以打开一次货架，查看最多三张食物。留在原地进入下一回合不会获得新货架；离开后再回来，才算一次新的光临。价格与牌库去向见第十章。

【配图：商店完整实机图，显示三张真实食物牌、价格、余额与购买按钮，正文全宽。牌面必须至少能读到名称和效果；不要使用 `docs/牌面验收/食物牌v2总览.png` 作为规则正文主图，那张总览适合校对40张资产，不适合新玩家阅读。】

### 6. 打工格

到达打工格后，可以开始一轮最长三个自己回合的连续工作。工作中的下一个回合会跳过正常掷骰与移动，直接回到打工地点；每次仍要由玩家确认继续。工资、精力消耗和中断条件见第十章。

### 7. 非遗研究所

地图上有四个研究所入口，分别位于襄阳、宜昌、荆门与武汉。它们连接同一份全局库存：一处放入的牌，可以在另一处买走。

有效到达研究所后，本次可以进入一次。关闭后仍留在行动阶段，并重新获得完整15秒。库存来源、买卖上限和价格见第十章。

【配图：使用 `tmp/gameplay-market-validation.png` 的构图作为参考，重新截取正常对局中的研究所购买页。弹窗占画面主体，余额、本次可购、购买/出售页签、牌面和价格均须可读；正式图裁成约4:3，占正文宽度80%至90%。再补一张较窄的出售页局部图。】

## 六、非遗牌：知识就是力量

当前数字版共有87张非遗牌，分属17个地区与7个类别。牌数会随资源增补而变化；涉及“集齐某地区”或“集齐某类别”的规则，一律按当前版本实际存在的牌计算。

每张非遗牌都有名称、地区、类别、基础分与文化介绍。同一张牌可以同时为基础分、类别组合和地域组合提供贡献。

### 1. 七个类别

| 类别    | 基础分 | 当前作用                        |
| ----- | ---:| --------------------------- |
| 戏曲表演  | 0   | 本人行动阶段使用，恢复3点精力             |
| 民间音乐  | 0   | 本人行动阶段使用，获得500积分点           |
| 手工技艺  | 1   | 本人移动阶段使用，本阶段最大步数翻倍          |
| 神话传说  | 2   | 响应其他玩家的食物或事件效果，抵消或转移自己受到的部分 |
| 节日庆典  | 3   | 从地区牌库抽得时立即恢复3点精力并获得500积分点   |
| 武术拳法  | 4   | 持有时，本移动阶段第一次移动总消耗减少1；多张不叠加  |
| 国家级非遗 | 5   | 正常收集与计分，当前不能使用              |

### 2. 主动使用

戏曲表演、民间音乐与手工技艺需要玩家主动使用：

- 戏曲表演和民间音乐只能在自己的行动阶段使用。
- 手工技艺只能在自己的移动阶段使用；每个移动阶段最多发动一张。
- 使用成功后，牌从手牌消失。非国家级牌进入全局研究所，但不会给使用者出售收入。
- 若时机不对、牌不在本人手中或本阶段已经用过同类限制牌，使用不会成立。

精力已经满12时，仍可按合法时机使用戏曲表演，但实际恢复量为0。是否值得这样做，由玩家自己决定。

【配图：查看非遗牌面与效果。使用真实非遗详情页说明名称、类别、分数、文化介绍与效果所在位置。】

### 3. 持有与获得时效果

武术拳法不需要点击使用。玩家持有至少一张时，每个移动阶段第一次实际移动的总精力消耗减少1，最低减至0；持有多张也只减1，牌不会因此离开手牌。

节日庆典在从地区牌库抽得时生效。非遗点收集，以及明确从某一地区牌库免费抽牌的效果，都会立即结算3精力与500积分点。它之后继续留在手中并参与计分；出售、买回、赠送、偷取或交换不会再次发奖。

### 4. 神话传说的响应

神话传说不是万能防御。只有当其他玩家的食物牌或事件牌效果将要作用到自己时，才会出现响应机会。玩家可以：

- 无效化自己受到的这一部分；或
- 把自己受到的这一部分转移给另一名合法玩家。

它不能响应自己主动使用的牌，也不能响应其他玩家的非遗牌效果。群体效果中，只有响应者自己的部分被改变，其他玩家照常结算。转移后的新目标还可以继续响应。

### 5. 国家级非遗

国家级非遗的单张基础分为5，没有特殊效果。

国家级非遗不会进入研究所，不能购买或出售。若某个效果要求“弃任意手牌”并弃掉国家级非遗，该牌直接离开本局。

### 6. 失去、赠送与交换

非遗牌离开手牌后，相关基础分与组合分立即重新计算：

- 使用或弃置的非国家级牌进入研究所。
- 出售的牌进入研究所，并获得售价。
- 赠送、偷取或交换只改变持有者，不经过研究所。
- 国家级牌不能进入研究所。

因此，手里的一张0分牌也可能很重要。它可能正好维持“五种不同类别”、某座城市的第五张牌，或一个类别的集齐条件。出手前可以先点开总分查看明细。

## 七、食物牌：民以食为天

食物不只恢复精力。高等级食物还会改变移动步数与消耗、带来卡牌、影响其他玩家，或在未来几个回合持续生效。

### 1. 等级、数量与价格

统一食物牌库共有60张：

| 等级  | 数量  | 商店价格   | 规则概况            |
| --- | ---:| ------:| --------------- |
| 市级  | 20  | 150积分点 | 统一恢复2点精力        |
| 省级  | 36  | 250积分点 | 每张有自己的效果        |
| 国家级 | 4   | 500积分点 | 稀少，效果更强或能永久改变能力 |

所有食物来自同一副牌库。商店、事件与牌面效果抽到的都是这60张中的实际牌；牌库不足时，只获得剩余的合法数量。

【配图：市级、省级、国家级各一张真实牌面。三张等高展示，牌名、等级和效果文字必须直接可读，不使用总览缩略图代替。】

### 2. 享用时机

食物只能在自己的行动阶段享用，每回合的基础上限为一张。

只有真正完成享用的牌才占用次数。以下情况不会把次数白白扣掉：

- 牌已经不在自己手中。
- 不是自己的行动阶段。
- 必须支付的公开成本不足。
- 同一张永久效果已经在本人身上生效过，牌面不允许重复。

纯恢复食物在精力已满时仍可享用。它会正常离开手牌、计入本回合次数与食物成就，只是实际恢复量为0。

把鼠标停在商店、背包或选择界面的食物牌上片刻，可以在牌旁查看效果文字。信息框会按文案长度收缩，不需要从卡面小字里硬猜。

【配图：食物背包与享用按钮。使用真实食物背包画面，保留食物牌、名称与“享用”操作。】

### 3. 一张食物怎样结算

点击“享用”后，先按牌面选好目标或卡牌；若效果会影响其他玩家，再依次给他们响应机会。全部处理完，这张食物才算享用成功，计入本回合次数与成就进度，并放回统一食物牌库底。

它不会被自己的抽牌效果马上抽回来。食物被其他效果弃置时，也会放回牌库底。

若享用前一切合法，但结算时发现隐藏牌堆或隐藏手牌里没有合适对象，食物仍算使用，并提示“无事发生”。公开且必然失败的条件则会提前禁用按钮。

### 4. 立即、延迟与永久效果

食物效果大致分为三类：

- **立即效果**：当场恢复精力、获得积分点或抽牌。
- **延迟效果**：作用于下个移动阶段、未来几个回合开始时，或跳过之后的阶段。
- **永久效果**：本局中持续提高步数、降低消耗或增加工资。

延迟效果生效时，信息栏会写出来源。若两个临时效果作用于同一个移动阶段，它们可以同时结算；但步数翻倍无论来自多少张牌，最终仍至多乘2。

移动减免以一个移动阶段为单位记录。分段移动只会继续消耗同一份减免额度，不会每点一次终点就重新得到一份。

同一张永久效果食物对同一玩家每局只生效一次。不同牌提供的永久加成可以按牌面共同存在。

### 5. 多人食物与响应

写着“所有玩家”的效果包含使用者本人；写着“其他玩家”的付款或损失不由使用者承担。目标只从存活玩家中选择。

多人效果会把每个目标的整份结果分开处理。例如一张牌让所有人“精力+1并支付100积分点”，某位玩家抵消时，只抵消自己这一整份；其他玩家继续恢复和支付。

支付积分点时不会出现负数。应付100而手里只有40，就支付40，牌面其他部分仍照常结算。

需要双方秘密交换非遗时，双方必须各选择一张非国家级牌，确认前只显示牌背；两边都选定后，两张牌同时交换。任何一方没有合法牌，交换就不能成立，食物仍会消耗并提示“无事发生”。

### 6. 牌面文字是最终答案

省级与国家级食物的具体效果，以牌面和探索图鉴中的正式描述为准。规则书负责说明它们如何结算，不把40张效果重新抄成一张难以查找的长表。

遇到“下个移动阶段”“永久”“随机获得”“从研究所获得”或“选择一名玩家”等字样时，可回看本章相应规则。未发现的食物会在探索图鉴中保持牌背，第一次以正面出现后才解锁。

## 八、事件牌：不成功，便成仁

停在事件格后，行动阶段会翻开一张事件牌。有些牌当场生效，有些要选目标，还有些会给其他玩家抵消或转移的机会。

### 1. 抽取与弃牌

当前事件牌库共40张。玩家本回合在事件格形成有效到达后，会在行动阶段开始时公开一张：

- 除五张可保留事件外，其余牌立即结算。
- 事件用后进入弃牌区，本局不洗回。
- 事件牌库耗尽后不产生新效果。
- 即使一张有效事件最后“无事发生”，它仍算已经公开和触发。

普通事件结算后，玩家仍在行动阶段，并恢复完整15秒。只有牌面明确写着跳过、结束或改变阶段时，才照牌面处理。

### 2. 五张可以保留的事件

以下事件抽到时仍要公开，随后收入持有者的事件牌手牌，只对持有者显示：

| 事件   | 使用时机               |
| ---- | ------------------ |
| 妙手回春 | 有玩家即将在回合末因精力为0而淘汰时 |
| 游目骋怀 | 持有者自己的行动阶段         |
| 畅行无阻 | 持有者自己的移动阶段         |
| 金蝉脱壳 | 其他玩家的卡牌效果即将作用于自己时  |
| 移花接木 | 其他玩家的卡牌效果即将作用于自己时  |

保留牌只在最初公开抽到时算一次事件触发；以后从手牌使用或响应，不会重复推进“公开事件”成就。

【配图：按当前本机发现状态排布五个保留事件卡位，宽屏3+2、窄屏2列或单列，每张至少240像素宽；已发现条目显示正面与短时机标签，未发现条目只显示牌背和“未发现”。事件牌背为2070×2910，正面使用当前资源引用的版本化资产。】

### 3. 选择与倒计时

事件可能要求选择地图格、玩家、卡牌或多个目标。

- 选择移动终点时，弹窗会收起，合法地图格沿用移动阶段的蓝色高亮；下方信息栏写出事件名、效果与“请选择移动终点”。
- 选择玩家时，地图会高亮可选玩家所在的格子，不再用一列机械按钮代替地图关系。
- 需要多名玩家时，必须达到牌面要求的人数，才会结束选择。
- 每一步有15秒。界面会显示当前是谁在选择或响应。

可选效果超时视为不发动。强制效果只要存在合法方案，超时会选择界面列出的第一个合法选项；强制多选则保留已经选好的内容，再按列表顺序补足最低数量。

“日行千里”属于可选移动，因此不选择或超时就留在原地，不会默认传送到地图左上角。

### 4. 资源或目标不足

牌面要求的数量不足时，执行最大合法数量。例如“获得两张食物”而牌库只剩一张，就获得一张；“弃两张手牌”而只有一张，就弃掉这一张。

完全没有合法对象时，牌正常结束并提示“无事发生”。必须先支付的发动成本若付不起，则效果不成立。

牌面造成的积分点损失或付款最多扣到0。禁止打工、禁止前往景区等持续状态会先排除不合法的目标，不会为了强制事件而绕过禁令。

### 5. 响应链

当其他玩家的卡牌效果作用到你时，若你持有合法的防御牌，系统会打开响应窗口，并明确写出响应玩家、来源卡牌和将要受到的效果。

金蝉脱壳可以抵消自己受到的这一部分；移花接木可以把这一部分转移给另一名合法玩家。转移后，新目标会获得新的响应机会，所以可能出现：

> P1的事件作用于P2 → P2移花接木给P3 → P3金蝉脱壳抵消。

原始出牌者始终是P1。P2不能因为把效果转走，就改写“其他玩家”“支付给谁”等牌面关系。

群体效果按玩家分段处理。P2抵消自己的部分，不会救下P3、P4；他们仍分别决定是否响应。

金蝉脱壳与移花接木可以响应其他玩家的事件、食物或非遗牌。神话传说类非遗只能响应其他玩家的事件或食物，不能处理非遗牌效果。所有这些牌都不能响应自己主动使用的牌。

### 6. 妙手回春

淘汰只在玩家自己的完整回合结束时发生。若此时精力仍为0，系统从濒死玩家本人开始，按顺位询问仍在游戏中且持有妙手回春的玩家；濒死者若自己持有，也可以先使用。任意一人使用后，濒死玩家恢复3点精力并继续留在游戏中。

这是独立的淘汰前窗口，不属于普通行动。持有者即使不是当前玩家，也可以在这个时机出牌。

### 7. 移动事件

事件造成的传送、换位默认只改变位置，不触发目标格。以下文字才会额外结算地点：

- “前往风景打卡点，并获得……”会按牌面登记风景。
- “终点为非遗点时，可免费学习一次”会额外执行一次学习。
- 没有类似说明，就不要自行补触发商店、事件、研究所或非遗点。

复杂移动与多人事件会暂时聚焦相关玩家，逐步展示骰子、资源变化或移动结果；演出结束后恢复之前的地图视角。按Enter或点击演出空白处只会加快当前一步，不会跳过规则结算或重新投骰。

【配图：事件公开后回到地图选择移动终点。以“沉浸体验”为例，先展示事件与效果，再展示蓝色合法终点；不使用普通地图或牌背代替。】

## 九、经济系统：决定上层建筑

积分点不直接计入总分。它可以在商店购买食物、在研究所补齐收藏，也会因为打工、食物与事件发生变化。

### 1. 支付不会超过余额

任何付款或损失都不会把积分点扣成负数。余额不足时，要先分清这笔钱是不是发动效果的必要成本：

- 若必须先付足积分点才能发动，付不起就不能发动。
- 若牌面是在结算中要求失去或支付积分点，就支付现有余额，最低降到0；牌面其余部分继续结算。

### 2. 商店里的消费

商店价格按食物等级固定：市级150、省级250、国家级500。每次光临从统一牌库抽出最多三张放上货架；只要余额足够，就可以购买其中任意张。离开商店时，未购买的食物按货架顺序放回牌库底。

买到的食物会先完成获得动画，再收入食物背包。关闭商店后，行动倒计时从打开前的剩余时间继续。

【配图：商店商品、价格与余额。使用正常对局中的真实商店画面，完整保留三张商品、购买按钮和余额。】

### 3. 打工里的收入

一次完整工作最多持续三个自己的回合，基础工资依次为250、300、350。每次确认打工时立即消耗1精力并领取当次工资，不是等三回合结束后一次发放；精力不足就不能继续。

连续工作期间，下一个自己的回合会直接来到行动阶段。在尚未确认本次打工前打开食物背包，或主动结束本回合，都会提前结束这份工作；完成第三次工作后也会自动结束。离开后不能再在同一处打工格开启新一轮，但可以去别的打工格。

“土家油茶汤”的永久加成会先加入本轮工资，再交给事件或分成规则处理。

若事件“坐收渔利”要求玩家去工作，先按该玩家当时生效的规则算出工资。工人与事件触发者不是同一人时，各获得一半；工人就是触发者时，由触发者获得整份工资。

### 4. 研究所价格

四个研究所入口共用一份库存，新游戏开始时库存为空。主动使用或被效果弃置的非国家级非遗会自动进入库存，但原持有者不会因此获得出售收入；国家级非遗不会进入研究所。

每次有效到达只能进入一次研究所：

- 最多购买3张，可出售任意张。
- 买满3张以后仍可继续出售。
- 刚出售的牌会立刻出现在全局库存中，可以再买回来；但要正常支付买价，并占用本次购买名额。
- 买卖完成后，手牌、余额与分数立即刷新。

非国家级非遗的出售价格由基础分决定：

> 出售价 = 250 + 50 × 基础分

买价是出售价格的两倍。

| 非遗基础分 | 售价  | 买价  |
| -----:| ---:| ---:|
| 0     | 250 | 500 |
| 1     | 300 | 600 |
| 2     | 350 | 700 |
| 3     | 400 | 800 |
| 4     | 450 | 900 |

国家级非遗基础分虽为5，但不参加研究所买卖，因此没有对应交易价。

出售会立刻让牌离开手牌，相关分数也随之重算。购买则相反：付款后牌进入手牌，并马上参与计分。若一张牌正在维持组合分，出售所得的积分点未必抵得上失去的分数，最好先打开计分详情确认。

## 十、职业：三百六十行，行行出状元

六种职业各有所长：有人能多吃食物，有人能整理牌堆，也有人更适合探索、经商、游览风景或打工。

职业在开局时互不重复。事件可以交换职业；交换完成后，双方立刻使用新职业的能力。

【配图：六职业使用真实水墨立绘做2列×3行布局，每项由立绘、职业名和技能短句组成。六张源图尺寸与纵横比并不统一，宽度1280至1818像素、高度1920至2720像素；排版时用同高的完整显示框，不直接拉伸图片。单名角色可见高度至少320像素，窄屏改成单列，不把六个人物强缩成一条。职业选择页与规则页可以共用同一媒体槽。】

### 1. 美食博主

美食博主每个自己的回合最多享用三张食物，其他玩家为一张。

次数只在食物真正享用成功后增加，并在下一个自己的回合开始时重置。三次享用都必须发生在本人行动阶段；被跳过行动阶段时，不能在回合外补吃。

这个能力增加的是次数，不会降低价格，也不会绕过食物自己的发动成本与目标要求。

### 2. 魔术博主

魔术博主抽取事件牌，或在非遗点收集时，会查看对应牌堆顶最多三张：

1. 选择一张获得或公开结算。
2. 排列剩余牌的先后。
3. 把剩余牌放回原牌堆顶。

排序界面最左边的牌，就是下一次最先抽到的牌。牌堆不足三张时有多少看多少；只剩一张时直接按普通抽取处理。

选择有15秒。超时会拿走当前最左边的牌，其余牌按界面当时的顺序放回。

未选牌只对魔术博主可见，其他玩家只会看到最后获得或公开结算的牌。

### 3. 探险博主

探险博主在自己的准备阶段和结束阶段，各有一次免费相邻移动：

- 只能前往相邻、有效、未被其他玩家占据的格子。
- 不消耗精力，也可以选择不移动。
- 禁止进入景区等状态仍然有效，被禁止的格子不会亮起。
- 选择相邻格期间仍可按Alt切换全局与追踪视角，不会取消本次选择。

准备阶段移动不会当场触发地点。如果之后的正常移动阶段没有离开这个格子，行动阶段会处理它；若移动阶段走到了别处，只处理最后的落点。

结束阶段移动也不当场触发，而且不会把地点效果留到下一回合。

探险博主正在连续打工时，只要技能移动成功离开，打工立即结束；选择原地不动则不结束。

### 4. 商业博主

商业博主拥有三项能力：

- 开局额外获得500积分点，因此以1000积分点开始。
- 在研究所购买非遗时，支付正常买价的一半；出售价格不变。
- 每次光临食物商店，可以免费刷新货架一次。

开局奖励每局只发一次，后来交换职业不会补发或收回。刷新机会按每次有效光临商店计算，离开后清零。

刷新时，货架上尚未购买的食物先暂时移开，再从牌库重新抽满三张；旧商品随后按原展示顺序放回牌库底。同一次光临只能刷新一次。

研究所的普通买价是售价的两倍。商业博主支付买价的一半，因此实际买价与这张牌的普通售价相同；出售价格不会因此提高。

### 5. 旅行博主

旅行博主更适合沿风景规划路线。

普通移动每次进入风景格时，该格精力消耗减少1：

- 平原风景从1降为0。
- 山地或湖泊风景从2降为1。

这项减耗既影响地图的蓝色可达范围，也影响系统选择哪条路线。它按每一个路过的风景格计算，不只看最终落点。

普通移动最终到达风景格后，进入行动阶段时额外获得250积分点。第一次打卡时，这笔积分与恢复3点精力会写在同一条信息里；重复到达没有普通精力奖励，仍会单独获得250积分点。

移动途中只是经过风景，不获得积分。游目骋怀、沉浸体验明确把玩家送往风景时也会结算250；普通传送、换位与探险博主结束阶段移动不会结算。

### 6. 生活博主

生活博主打工不消耗精力，工资、连续三回合与同一地点只能工作一轮的规则保持不变。

事件“坐收渔利”要求生活博主前往打工时，也按0精力处理。禁止打工等状态仍然有效，职业能力不会强行绕过。

### 7. 职业交换与技能封锁

“交换人生”等效果会让双方职业同时互换。交换完成后，职业名称、立绘、详情与能力立即刷新；已经发过的开局奖励不会追溯重算。

“孤注一掷”会封锁事件触发者的职业技能四个自己的回合，从抽到它的当前回合开始计数。封锁跟随玩家，不跟随职业：即使后来与别人交换职业，原玩家身上的剩余封锁仍在，另一名玩家不会替他承受。

封锁期间，玩家仍保留职业身份，只按普通玩家规则处理相应操作。例如美食博主只能吃一张，生活博主打工重新消耗精力。

## 十一、成就：挑战不可能

成就牌每项只有一张，谁先完成条件，谁就立即获得并计入总分。

### 1. 怎样获得成就

成就不需要点击领取。食物享用、事件公开、风景打卡、精力变化或非遗手牌变化发生后，系统会立即检查相关条件。

领取成功时：

- 成就牌进入玩家右侧的成就区。
- 成就分立即加入总分。
- 屏幕出现一条不打断操作的短提示。
- 该成就从公共池中移除，其他玩家不能再获得。

大多数成就一旦领取，就不会因为后来失去条件而撤回。例如玩家凭一组非遗获得成就后再出售其中一张，成就仍保留。

**食物：** 只有完整享用成功才计数。满精力时合法享用仍计；购买、抽到、交换、弃置或使用失败不计。

**事件：** 合法公开并进入结算就计数。有效事件即使最后无事发生也计；空牌库不计。可保留事件只在初次抽取公开时计一次，之后从手牌使用不重复。

**风景：** 同一玩家第一次登记一处风景才计一次。游目骋怀与沉浸体验可以登记打卡，其他传送和换位不登记。首次由这两张事件打卡时，只获得牌面规定的5点或6点精力，不再叠加普通风景的3点。

**神农架收藏：** 非遗与风景数量按当前工程实际资源统计，两边都必须有有效内容。获得野人后，即使后来失去神农架非遗，也不撤回。

**精力：** 必须实际达到12。已经是12时再出现“+3”但实际变化为0，不会靠这次无变化重复触发。

### 4. 成就升级

升级类的成就，获得进阶成就时，低阶成就牌会被销毁。

例如“饕餮”和“大胃袋这一块”，这两项成就各自全局唯一，获得“大胃袋”不要求玩家先持有“饕餮”。

任何玩家获得“大胃袋”时，本局“饕餮”立即销毁：

- 若尚未被领取，直接从可领取成就中移除。
- 若已经在某位玩家手中，从该玩家成就区移除，并立即扣回2分。
- 持有者是升级者、其他玩家或已淘汰玩家，都按同一规则处理。

被销毁的低阶成就牌本局不会再次出现。

## 十二、分数怎样计算

总分只看结算当下仍在玩家手里的非遗牌与仍然持有的成就。积分点、精力、食物牌和事件牌本身不直接计分。

> 总分 = 非遗基础分 + 类别组合分 + 类别集齐分 + 地域组合分 + 成就分

同一张非遗可以同时贡献基础分、类别条件和地域条件。

【配图：真实计分详情弹窗全宽展示，保留五个分项和总分。另在下方用箭头把右侧手牌区的具体卡组连到对应分项。重新截取当前工程画面，不使用单张武当武术牌代替计分系统。】

### 1. 非遗基础分

把当前持有的每张非遗基础分相加：

| 类别    | 每张基础分 |
| ----- | -----:|
| 戏曲表演  | 0     |
| 民间音乐  | 0     |
| 手工技艺  | 1     |
| 神话传说  | 2     |
| 节日庆典  | 3     |
| 武术拳法  | 4     |
| 国家级非遗 | 5     |

0分牌仍然可以组成类别、地域与集齐奖励，也可能带来强力能力。基础分低，不等于这张牌没有价值。

### 2. 类别数量组合

先分别统计每个类别的持有数量：

| 单一类别持有量 | 数量档奖励 |
| ------- | -----:|
| 至少3张    | +2    |
| 至少5张    | +3    |
| 至少10张   | +5    |

这张表有两条容易读错的规则：

1. 同一类别只取达到的最高档。10张得到5分，不再叠加3张的2分和5张的3分。
2. 不同类别的数量档也不相加，只取所有类别中最高的一档。

例如，手工技艺5张、民间音乐3张，数量档只得3分，不是3+2。

此外，只要手里至少出现五种不同类别，再加5分。这里说的是“持有五种类别”，不是“集齐五个完整类别”。国家级非遗也算一种类别。

### 3. 类别集齐

每集齐一个类别的全部实际非遗，再加5分。多个类别都集齐，可以分别累计。

“全部”按当前版本实际资源计算，不沿用旧说明书中的固定张数，也不会把不存在的空类别当作自动集齐。

类别集齐分与上一节的数量档、五种类别奖励可以同时获得。

### 4. 地域组合

每座城市分别检查：

- 持有该城市至少5张非遗，该城市加5分。
- 集齐该城市全部实际非遗，该城市再加2分。
- 两座城市分别达到5张，就分别获得5分。
- 同一座城市若同时满足“5张”和“集齐”，两项叠加，共加7分。

另有一项江汉三市组合：同时持有潜江、天门、仙桃至少各一张，加2分。这个奖励只算一次，不会随三市卡牌数量重复增加。

三座城市各自的集齐奖励仍可与江汉三市叠加。例如当前版本中，若某位玩家集齐潜江、天门与仙桃三市，三座城市各加2分，再获得江汉三市2分，地域部分共加8分。

右侧手牌区会按城市整理卡牌。某项地域组合达成时，对应城市下方会写出加分来源。

### 5. 成就分

把玩家当前持有的成就分相加。若饕餮被大胃袋销毁，原持有者立即失去2分；除此之外，已经获得的成就不会因为后来失去达成条件而撤回。

成就可能让玩家在行动阶段中途越过目标分，但游戏仍会等完整回合结束后再检查是否进入结算。

### 6. 一份完整例子

假设一名玩家手中有：

- 3张戏曲表演，基础分0。
- 5张手工技艺，基础分共5。
- 1张民间音乐，基础分0。
- 1张神话传说，基础分2。
- 1张节日庆典，基础分3。
- 没有集齐任何完整类别。
- 其中5张来自武汉，但尚未集齐武汉；此外，潜江、天门、仙桃各至少有1张。
- 还持有一项2分成就。

那么：

| 分项     | 计算                | 得分     |
| ------ | ----------------- | ------:|
| 基础分    | 0 + 5 + 0 + 2 + 3 | 10     |
| 类别数量档  | 最高为手工技艺5张         | +3     |
| 五种类别   | 持有五种不同类别          | +5     |
| 类别集齐   | 没有                | +0     |
| 同城5张   | 一座城市达到5张          | +5     |
| 江汉三市   | 潜江、天门、仙桃各至少1张     | +2     |
| 成就     | 一项2分成就            | +2     |
| **总分** |                   | **27** |

如果他随后出售一张维持“五种类别”的牌，系统会重新检查基础分、类别与地域条件。若卖掉的牌还维持着同城5张、集齐全市或江汉三市，相应地域分也会一并失去；总分可能不只少掉那张牌的基础分。

### 7. 分数会随手牌变化

以下行为会立即重算总分：

- 收集、购买、获赠、偷取或换入非遗。
- 使用、出售、弃置、赠出、被偷或换出非遗。
- 获得成就，或饕餮被销毁。

最终结算使用当时的最新手牌和成就，不会把“本局曾经拥有过”的牌继续算进去。

## 十三、淘汰、结束与最终排名

### 1. 精力为0时先把回合走完

精力降到0时，棋子不会立刻消失，按钮也不会马上全部锁死。当前玩家仍完成行动阶段，可以享用食物、使用戏曲表演或等待其他恢复效果。

只有自己的结束阶段完成、即将把回合交给下一位时，精力仍为0，才先开启妙手回春响应；无人救回，才正式淘汰。

其他玩家在事件中把你的精力降到0，也不会当场淘汰你。等到你自己的回合结束，再看那时的实际精力。

### 2. 淘汰之后

被淘汰玩家的棋子离开地图，不再获得正常回合，也不再是“选择一名存活玩家”类效果的合法目标。

淘汰不会清空该玩家的非遗牌与成就。最终结算时，他仍会和其他人一起计算总分，也可能凭已有收藏得到很高名次。唯一需要特别留意的是：若他持有的“饕餮”后来因其他玩家获得“大胃袋这一块”而被销毁，仍会扣回2分。

### 3. 多人局什么时候结束

2至6人局在一名玩家的完整回合结束时检查：

- 任意玩家达到本局目标分数；或
- 本局累计淘汰2人。

满足任意一项就进入结算。两人局也需要累计淘汰2人；只淘汰一人不会结束，除非同时有人达到目标分数。

若同一回合末两项都满足，界面显示“胜利条件达成”，不改变排名算法。

### 4. 单人局

单人局只与自己的路线和资源周旋：

- 回合末达到目标分数，获胜。
- 回合末精力为0且尚未达标，失败。
- 若同一个检查点既达到目标又精力为0，以达标为先，判为胜利。

### 5. 达标的人不一定是冠军

目标分数只是让对局进入结算的条件。进入结算后，系统重新计算所有玩家的最终总分，再从高到低排名。

例如，P2在P1的事件中获得一张非遗并越过目标分。游戏仍等P1完整回合结束；结算时若P3的最终总分更高，冠军是P3。

### 6. 并列与名次

总分相同者并列，采用竞赛排名。例如两人并列第一，下一名是第三，显示为1、1、3。

多人局中，并列第一的玩家全部是冠军。玩家编号只决定同分卡片在界面上的稳定排列顺序，不是隐藏的决胜条件。单人挑战失败时仍展示最终得分，但不产生冠军。

### 7. 正式结算

结算界面依次展示：

1. 游戏结束与结束原因。
2. 各玩家的基础分、类别组合分、类别集齐分、地域组合分与成就分。
3. 玩家卡按最终总分重排并显示名次。
4. 冠军展示。

动画可以加快或直接跳到最终状态，结果不会改变。进入终局后不能关闭结算界面回到棋盘继续操作。

## 十四、常见裁定

这一章处理牌面上最容易发生争议的说法。若牌面另有明确说明，以牌面为准。

### 1. “可以”与“必须”

写着“可以”“可选择”或明确询问是否发动的效果，可以放弃，超时也视为放弃。

写着“必须”“立即”，或直接要求玩家完成一项选择的效果，只要存在合法方案就要执行。超时会从合法方案中按界面顺序代选，防止对局停住。

### 2. “最多”与“最大合法数量”

资源或目标不足时，尽可能执行实际能完成的数量，不会凭空补牌，也不会因为差一张就把整张效果取消。

“最多两张”允许选择0、1或2张；“获得两张”而牌库只剩一张，则获得一张。

### 3. “所有玩家”与“其他玩家”

“所有玩家”包含效果使用者；“所有其他玩家”不包含使用者。除非牌面另有说明，只从仍然存活的玩家中选择目标。

群体效果按每名目标分别响应。某人抵消自己的部分，不会让整张牌一并失效。

### 4. 并列最高、并列最低

效果寻找积分点、分数或手牌数量的最高者、最低者时，所有并列者都受影响，不用玩家另选一人。

### 5. 最近地点与等距

“最近”按地图六角格的连通关系，比较最少需要经过多少步；不比较沿途地形消耗。若有多个等距地点，由被移动的玩家选择；超时则选择界面列出的第一个合法地点。

禁止打工、禁止景区或支付不起必要精力的目标，会先从合法地点中排除。

### 6. “未来N次阶段”

计数从效果结算以后开始，已经经过的当前阶段不回头计算。

多个跳过标记按施加顺序排队，每次只消耗一个。若本次阶段已被更早的标记跳过，后来的跳过标记不会一起消耗；还没有用上的步数加成与精力减免，也会留到下一次实际可操作的对应阶段。

### 7. 到达、路过、传送与换位

- **路过：** 支付地形消耗，不处理地点功能。
- **有效到达：** 正常移动完成并作为本回合最终落点。其他特殊移动是否会在行动阶段处理落点，以该效果本身的说明为准。
- **传送或换位：** 默认只改位置，不处理目标格。
- **明确落点效果：** 牌面写了打卡、学习等内容时，额外照文字执行。

### 8. “无事发生”

以下情况通常会显示“无事发生”：

- 牌库或研究所为空。
- 没有合法目标。
- 可选效果被放弃或超时未选。
- 效果被完整抵消，且没有产生其他变化。
- 牌面条件无法产生任何实际结果。

无事发生不等于没有抽到事件。已经公开进入结算的事件在结算后仍会弃置，也会计入事件公开进度。

### 9. 隐藏信息

其他玩家的私密手牌、牌库未来顺序和未公开随机结果不能用来提前判断按钮是否可用。

例如，某张食物会抽取特定地区非遗。即使该地区牌库在隐藏状态下已经抽空，按钮也不会借此泄露信息；享用后才会提示无事发生。

### 10. 数量以当前版本为准

涉及“全部非遗”“集齐某类”“集齐某市”或“全部风景”的条件，都从当前实际资源与地图统计，不沿用旧说明书中的固定数字。

- 三图并列：每图至少占正文宽度的30%；达不到就改为纵向排列。
- 图中文字不得小于同页辅助文字。若看不清牌面效果，就在图旁排正文，不要继续缩牌。

### 4. 风格与位置

- 图片放在它所解释的规则之后，读者先知道要看什么，再看图验证。
- 真实UI优先于抽象图标；抽象流程图只用于解释先后关系。
- 保留项目已有的棕金色、米色和地域色，不再为说明书另造一套蓝紫色系统。
- 普通移动合法格使用游戏现有蓝色高亮。黄色只用于普通状态下的鼠标悬浮反馈，不混入移动示意。
- 卡牌、截图与流程箭头对齐到统一媒体槽，周围保留足够留白。装饰纹样只作边框，不压住规则文字。

### 5. 接入游戏前的逐页检查

每一页至少检查：

1. 图片是否真的对应本页规则，而不是泛泛的项目宣传图。
2. 图片中的名称、数字、按钮状态是否来自当前版本。
3. 1920×1080与1280×720下，关键文字是否仍能读清。
4. 4:3与超宽屏下，图片是否被裁掉关键区域。
5. 键盘和手柄焦点切换时，图片与正文是否会滚入可见区。
6. 未发现的食物、事件与成就是否被图片提前泄露。
7. 同一张素材是否被无意义地重复使用。
