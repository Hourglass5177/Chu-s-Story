# 事件系统实现审计

审计基线：Godot 4.6.2 当前工程。旧构建版不作为验收依据。

## 系统结论

- 事件资源共 40 张：39 张可用，仅“孤注一掷”因依赖职业技能而不入牌库。
- 39 张可用牌均有明确效果分派和确定性效果测试；测试不再允许未知事件 ID 默认通过。
- 抽牌、弃牌由 `ResourceManager` 管理；选择、响应、持续状态和阶段影响由 `EventManager` 管理。
- 事件移动默认不触发目标格；实际到达事件格用到达编号防止重复触发。
- 每步选择独立计时 15 秒。可选项超时放弃，强制项超时从合法项随机选择。
- 结算期间暂停行动计时；普通事件结束后仍处于 ACTION，并重置为完整 15 秒。
- 金蝉脱壳、移花接木和神话传说牌按玩家逐段响应。转移后整段效果改用最终合法目标，原始出牌者始终不变，不能响应自己的牌。
- 资源不足时执行最大合法数量；事件扣分不会把积分点扣为负数。

## UI 与运行验证

- 事件弹窗复用项目现有棕金边框、米色底纹和像素字体；普通选择与长列表均已做实际渲染检查。
- 右侧手牌区保留原非遗牌分组逻辑；只有持有保留事件牌时才追加“事件牌”和卡片，不显示数量、空态或说明文字。
- 保留牌详情只显示牌面、效果、使用时机和必要按钮，不显示倒计时。
- 真实 15 秒超时验证：事件期间 ACTION 计时暂停；超时后弹窗隐藏、模态深度归零、阶段仍为 ACTION，计时恢复为完整 15 秒。
