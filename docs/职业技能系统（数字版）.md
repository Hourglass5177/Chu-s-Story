# 《楚物志》职业技能系统（数字版）

本文件记录当前数字版正式职业规则。职业名称与基础效果以《角色牌 新.pdf》为依据；触发时机、超时处理及与事件、打工等系统的交互，以本轮确认的数字版裁定为准。

## 通用规则

- 职业技能在满足条件时自动生效；需要选择时进入独立的 15 秒操作窗口。
- 职业技能被封锁时，玩家仍保留当前职业身份，但按普通玩家规则处理对应操作。
- 职业交换只交换职业身份。已经存在的技能封锁跟随玩家，不随职业转移。
- 职业详情与技能剩余封锁回合可在玩家信息区查看。

## 六个职业

### 美食博主

- 每个自己的回合最多享用 3 张食物，其他玩家仍为 1 张。
- 次数仅在食物实际享用成功后增加，并在下一个自己的回合开始时重置。

### 魔术博主

- 抽取事件牌或从非遗点收集非遗牌时，查看对应牌堆顶最多 3 张，选择其中 1 张获得或结算。
- 其余牌由玩家排列后放回原牌堆顶；未选牌中最靠左的一张是下一次最先抽到的牌。
- 牌堆不足 3 张时有多少查看多少。只有 1 张时直接按普通抽牌处理。
- 选择超时时默认选择所列第一张，其余牌按原展示顺序放回牌堆顶。

### 探险博主

- 在自己的准备阶段和结束阶段，可以各选择一次免费移动到一个相邻、有效且未被其他玩家占据的格子。
- 两次技能移动都不消耗精力，也不会在移动发生时立即触发格子效果。
- 准备阶段成功移动会登记为本回合到达；若之后的移动阶段没有移动离开，则在 ACTION 开始时按最终落点正常结算事件、风景、商店或研究所等效果。若移动阶段再次移动，则只按最后的普通移动落点结算。
- 结束阶段成功移动不登记为下一回合的待结算到达，落点效果不会延迟到下回合触发。
- 可在信息栏直接选择“不移动”；不选择或超时也会留在原地。若玩家正在连续打工，任一阶段成功移动后立即结束打工；留在原地则不结束。
- “闭门谢客”等禁止前往景区的状态仍然生效，对应风景格不会成为合法终点。

### 商业博主

- 游戏开始时额外获得 500 积分点，因此以 1000 积分点开局。该奖励每局只结算一次；之后交换职业不会补发或扣回。
- 在全局研究所购买非遗牌时，支付正常买价的 50%。出售价格不变。
- 每次光临食物商店可免费刷新货架 1 次；离开商店后，本次光临的刷新次数清零。
- 刷新时先抽取新货架，原货架未购买的食物牌随后按原展示顺序放回牌库底。

### 旅行博主

- 普通移动每次进入风景格时，该格精力消耗减少 1：一般地形风景格消耗 0，山地或湖泊风景格消耗 1。该减耗参与可达范围和路线选择计算，经过多个风景格时逐格生效。
- 每次按普通移动规则最终到达风景格后，在进入 ACTION 时额外获得 250 积分点；MOVING 中途经过不结算，同一风景重复到达仍可获得。
- 首次打卡时与原有 3 点精力合并结算和提示；重复打卡时单独提示职业积分。
- “游目骋怀”和“沉浸体验”明确前往风景格且移动成功时，同样额外获得 250 积分点。
- 其他传送、换位和探险博主的结束阶段邻格移动不触发该奖励。

### 生活博主

- 打工不消耗精力，工资和连续打工规则不变。
- “坐收渔利”要求其前往打工时，同样按 0 精力消耗处理；禁止打工等限制仍正常生效。

## “孤注一掷”

- 事件触发后，触发者的职业技能从当前回合起连续封锁 4 个自己的回合，即当前回合和之后 3 个自己的回合。
- 当前回合算第 1 个受影响回合；本回合结束时，剩余封锁回合由 4 减为 3。
- 该牌只作用于事件触发者，不能响应自己触发的事件。结算完成后继续当前 ACTION。
- 封锁只停用职业技能，不改变职业身份，也不影响职业身份被事件交换。

## 事件联动

- “交换人生”通过职业系统原子交换两名玩家的职业，并立即刷新职业资料与技能状态。
- “坐收渔利”按最终打工玩家的实际职业技能和食物工资加成计算工资，再进行分配。
- “游目骋怀”和“沉浸体验”移动成功后结算旅行博主的风景奖励。
- 40 张事件牌现均为可用资源并进入当前牌库；“孤注一掷”不再是职业依赖的延期牌。
